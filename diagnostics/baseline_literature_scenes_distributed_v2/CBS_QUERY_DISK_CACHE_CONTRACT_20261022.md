# 低层 A* 进程间精确计算缓存：契约与部署门

本文件描述候选计算优化。部署以 `CBS_QUERY_DISK_EQUIVALENCE_20261022.receipt.json` 和 `CBS_QUERY_DISK_PIPELINE_CODE_20261022.receipt.json` 为门；收据不存在时研究调度不使用该候选。

## 复用对象与等价关系

复用对象是现有 `astar_constrained` 的确定性子程序结果。适用范围是冻结 Grid 调用的合法、有限输入、现有浮点运行环境及独立的输入/输出数组。仅 `nr == 0` 的 CBS 查询走此缓存，其他调用执行原搜索。

原搜索源码在移除缓存块和导出接口后逐字节还原为 `cbs_kernel_flat_cache.cpp`。原内存缓存证明见 `CBS_START_SIGNATURE_THEORY_20261022.md`：连续起点只影响起点网格、初始九条边/初始终点测试的十个布尔判定，以及返回路径的第一点。网格起点、这些判定和其他精确参数相同，原搜索的后续堆顺序、父节点和路径后缀相同。

共享键进一步包含分辨率、inner/outer/sep、margin、完整 bounds/walls 字节；原查询键包含网格起点、时域、目标 float64 字节、非零时刻约束的数量/顺序/完整字节、十个初始判定位和舍入模式。另加入端序、SSE 浮点控制位及 x87 控制字。时间零约束的影响由完整初始判定表示，不影响后续时刻。

命名空间由候选 C++、新头文件、原精确键头文件和实际共享库二进制的 SHA256 派生，分别隔离不同原型/编译结果。缓存路径中不使用场景、controller 或 η 的近似身份；相同子程序输入可来自不同上层调用，但研究 rollout 身份与标签保持各自独立。

## 值、并发与容量

条目保存路径点数和路径数据，第一点规范化为零，读取后由本次真实起点恢复，包括负零位。无路径结果以零点数保存。

SHA256 的前 16 位只用于选择 65536 个直接映射槽之一。读取必须同时通过格式、长度/点数上界、完整条目 SHA256 和完整键逐字节比较；槽碰撞是未命中。每槽最多 16 KiB，槽数据最多 1 GiB，另有文件系统元数据与小型临时文件。过大的结果不落盘。

每个 worker 仍串行执行一个查询；不同进程通过各自临时文件、完整写入、fsync 和原子 rename 发布条目。读者持有完整旧/新 inode，不读取半写条目。目录和文件使用受限名字及 O_NOFOLLOW。无全局等待锁；缓存未命中、损坏、碰撞或 I/O 错误回退到原搜索。

缓存槽置换只发生在本轮新建的 `runtime_cbs_query_memo_candidate_20261022/` 临时计算目录。条目由同一受验证子程序产生，不接收外部导入结果。此目录不作为研究 raw、轨迹、checkpoint、journal 或数据库；不封存其中可置换的缓存槽。研究证据文件不参与置换。

仅约束非空且原计算耗时至少 0.01 秒的查询默认写入共享缓存；这是计算缓存的准入条件，未命中仍执行完整原搜索。验证可把准入耗时设为零，以覆盖快速/失败查询的存储路径。

## 对完整执行的影响

同一输入查询返回相同路径后缀与本次起点，因此上层 CBS 得到相同路径、分支和规划记录。控制器、两次安全投影、修正基、切换规则、物理推进与事件判定保持原函数；由逐步归纳，完整物理轨迹与成功/碰撞/超时/unknown 判定相同。时域、节点预算、几何、容差、精度、菜单、seed 和统计定义没有变更。

科学 preflight、UID、官方 cache_writer 和单进程 merger 不变。保存轨迹回放用于验证新计算实现，不发布新研究标签，不写实验 journal，不计入研究 rollout 样本。当前标签 worker 保留已验证内存版本，后续评估/动力学/变体才接入通过部署门的共享版本。

## 验证与性能解释

存储测试覆盖正/负结果、实际槽碰撞、512 次多进程原子替换、损坏/截断、容量拒绝和禁用回退。冷/热缓存分别进行 644 个网格逐位比较；四场景 17 个历史查询和 12 个实际 IEEE 零/约束输入逐位比较路径、名义输出与规划记录。完整验证比较保存的 2000 步轨迹的所有非计时数组及结果字段，并分别测冷缓存和新进程热缓存。

此前跨 η 探针中，理想串行共享使实际原生搜索从 1118 次降到 531 次；这只是复用潜力。并发进程可能同时计算同一冷查询，生产内存缓存也会跨局保留，因此该比例不是生产提速倍数。CPU 墙钟受缓存冷热及并发影响，仅作为运行成本；任务时间仍按仿真步数计算。性能结论以实际验证和生产遥测为限。
