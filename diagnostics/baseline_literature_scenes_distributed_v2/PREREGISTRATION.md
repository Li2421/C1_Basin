## 固定输入和场景

状态来自 v1 已封存的 FLOW_STATES_UNCHECKED.json，不再调用采样器。窄通道场景和门口场景各 64 组；二维拥挤随机场景去掉边界墙，每 N=2/4/6/8/10/12/14 按原顺序选前 16 个几何有效样本，共 112 组；圆形围场五机随机场景选前 16 组。去墙后的全部 700 组几何核验记录保留，不能按 outcome 补抽。其余半径、周期、速度界、时限、到达停止与 native swept 碰撞事件不变。拥挤随机时限沿用 v1 已执行的 333 步（49.95 秒），不使用旧构造函数的 ceil=334。

8 类 48 个 controller 实例与超参数逐字复用 CONTROLLER_MANIFEST.json。名义控制器每个物理步调用一次，保留状态型优化器的 warm start；本轮分布式的是安全层和修正，不能宣称这些联合 controller 具有独立观测部署能力。拥挤随机通过只读几何视图选择原零墙代价分支，其他数组与参数不变。圆形内圆零代价证书与搜索父表存储优化只作计算等价后端，须通过历史回放，不改搜索预算、分辨率、样本、代价或随机数。

## 执行与单元门

名义 → 原速度界/到达停止 → 安全投影 → 修正 → 同一投影 → 原物理执行。每台机器人只解自己的二维速度，约束不含他人的名义或投影动作。所有其他机器人当前位置同步可见，无感知截断。窄通道、拥挤随机、圆形主线的责任系数 c=1/2，门口 c=1；墙全责。默认 HardProjectionConfig 全部数值不变。不得加松弛、优先级、回退控制器或步后修正；仅原同问题数值重试。控制计算异常保存为 unknown，不重跑。

逐机器人 local_basis 使用第 28 轮的 Bgoal、Bperp、Brel，Brel 是先逐配对限速、再对所有其他机器人平均，N=1 扩展为零。组件对照原 OrthoFlow3，数值误差如实记录。两次投影均执行，不能因 η=0 就跳过第二次。η10 与 η13 精确 float64 值及 12 动作菜单复用已封存 JSON，不重抽候选。人定双 η 从 η13 开始，平均原进度首次 ≥0.968 或物理步 t≥round(6H/7) 后切到 η10，广播同一标量；零初始距离的定义与 v1 相同。

在任何新研究 rollout 前：三个旧能力门各选 state0/agent0/seed0、每类型第一个实例，共 24 条 N=1 完整回放，首动作、事件、步数和完整位置必须逐位相同；另复现 v1 的 16 条圆形旧记录与 16 条已封存搜索存储回放记录。历史回放只用于工程门，不登记成新标签。单元测试覆盖 N=1 的同问题投影、责任系数代数、机器人编号交换、local_basis、无墙代价与 native 碰撞一致性。冻结实现与门收据后再做能力门 preflight/提交。

## 标签、训练与冻结

窄通道、门口沿用旧 32/32 划分。拥挤随机训练用 N=8、14 在主 state 之后各 16 组，评估用主 state 的这两个 N，共 32 组。圆形训练用 index16–47，评估 index0–15。每类型清单前两个实例、训练 state、同一 12 菜单动作、seed0 生成标签；η0 与已完成同身份基线标签精确复用。32 个训练 state 与评估 state 不相交。

模型和训练规则逐字复用 v1 learn_critic.py：physical12 拆为9维几何和3维上下文，19维动作编码，96/32/32适配器、128/64共享层，seed17/23/41集成，AdamW 1e-3、weight_decay1e-4、梯度裁剪5、batch256，100至2000步每100步保存。8类留一；内层仅用源类型选 checkpoint，unknown 标签 masked。每个评估 controller 使用未见过其类型的折。按 v1 评估全部48实例，主结论只纳入合格者；选择在首条评估 rollout 提交前密封。若场景全部合格者基线下界均≥98%，按预设规则仅做固定修正，不训练。冻结零样本仍为 N/A，不改模型。独立评估不补完整12动作 oracle；训练完整菜单和独立四臂参照分开报告交叉拟合与样本内值。

## 失败、比较和统计

从保存的 positions、nominal、first-safe 重算诊断，不重跑 controller。W∈{2.5,5,10}秒、τ∈{.02,.05,.1}，主值5秒/.05，活跃线性行残差≤1e-7、非零名义阈值1e-6、投影改写阈值为原 intervention_tol，频率≥90%，静止窗口位移小于半径，均沿用 v1。逐机器人锥只用该机器人的实际起作用行；集中式取对应速度块。至少一条配对活跃行为4a′，只有墙行为4a″；其他分类保持 v1 互斥顺序，unknown 单列，timeout不等于deadlock。圆形静止窗口尺度不足的既有局限必须报告，操作候选不能冒充严格无限时域平衡证明。

旧联合锥判据使用 v1 的耦合配对行，在两层下均重算；同时另存分布式实际块对角约束的联合锥，不能混淆这两种可行集。逐机器人实际约束的低残差与非零 safe speed、非零活跃边界偏置分开报告。

controller级失败阈值≤5%，状态相关失败阈值(5%,95%)，并报至少一个state有4a′的实例数。unknown存在时按成功识别区间给确定/可能计数；去除分析只去除上界仍≤5%的确定失败实例。它们仍进入总体，不能当作死锁证据。普查只描述，不宣称共享几何。

逐场景与四场景合并均按类型→controller→state逐层等权；合并将每个controller的有效(scene,N,index)状态池先平均，场景不强制等权。bootstrap5000次，seed0/1同簇，两安全层、所有方法共同配对。unknown率保留，成功下界临时代0、上界代1，另给差值相容上下界。报告层间各方法差、各自修正减基线、两者增益之差；学习减三种固定各自的配对差及减最佳聚合固定值，bootstrap内重选最佳，另报逐controller交叉拟合固定oracle。碰撞、超时、伤害episode数与下降≥10个百分点controller数分开。集中式拥挤随机/圆形没有重新学习请求，表中该格记 N/A，不能用其他场景填补。

同一物理state在不同安全层下保持同一state_uid；新执行语义由新controller执行指纹区分。RNG严格沿用PRNGKey(2026102004)、state_uid哈希、seed、物理步，不能让安全层名字改变随机数。去墙场景使用新scenario/state身份，两层共享这个身份。确定性名义朝目标、梯度优化与两个搜索类型可按明确不使用key的代码证明复用另一seed的完整轨迹，但须保留不同请求身份、源hash和零新增物理步声明；其余随机策略不得这样处理。

## 第二阶段：提前写定的非主线参数

第一阶段主线完成后做。双积分器跟踪 a_nom=(v_des−v)/dt，窄通道/拥挤随机按1.5 m/s²范数界裁剪，速度界1；圆形不设加速度界。窄通道与拥挤随机固定 l0=1、l1=2（λ=1的临界阻尼辅助屏障，λdt≤.2满足辅助Euler正因子条件），圆形 l0=6、l1=5。速度屏障γ=1。窄/拥挤按论文前向Euler模型，圆形按保持加速度的双积分器。最小违反解使用先最小最大线性约束违反、再最小跟踪目标的词典序定义；记录每步约束违反，不能记为unknown或加另一控制器。

门口前视距离0.025m，保守半径0.125m；初始朝向0，线速度界[-.26,.26]、角速度界[-3.8,3.8]，离散CBFγ=.1，真实他人半径、同一有限墙几何。前视点与姿态离散化、同问题数值算法及精确输入约束将在第二阶段实施收据中写明，不能按第一阶段成功率调这些已固定参数。修正在期望速度层，加跟踪与同一安全层；判据在加速度/前视点速度层。辅助Euler正因子本身不证明保持加速度下原h全区间非负，也不保证不相容约束可行；报告必须给完整条件、实际采样间检查、违反和缺少全局离散安全证明的边界，不将采样无碰撞当作定理。
