# 第二阶段实施约定（新研究rollout前固定）

参数沿用已封存PREREGISTRATION.md；本文件固定数值求解与离散模型的剩余实施细节，不按第一阶段结果调参。第二阶段在第一阶段数字封存后运行，只做合格实例、全部既定主state、seed0–1、只加安全投影和三种固定修正；不训练critic。当前合格数44/44/45/45，条件公式51328+896Q给出90752个请求，提交前另作精确清单和官方preflight。

窄通道/拥挤随机使用论文前向Euler：p+=dt*v，v+=dt*a；连续步内位置沿旧v线性插值。圆形使用保持加速度的精确零阶保持p+=dt*v+dt²*a/2、v+=dt*a；其配对与有限墙线段距离均求完整区间最小值，解析多项式临界点而非离散采样。墙段筛选仅用距离函数1-Lipschitz下界排除不可能取到最小值的段，不改实际最小值或碰撞事件。物理半径、墙、碰撞阈值、位置到达容差、时限沿用第一阶段；另报速度收敛，成功仍用原位置任务标准。没有步后裁剪或位置修复。

双积分器每台解二维加速度：配对F的非加速度项为2||dv||²+2*l1*d·dv+l0*h，责任为一半；墙用有限段距离的梯度及分段Hessian计算相对阶二约束；速度屏障为-2v·a >= -(vmax²-||v||²)。加速度范数上限1.5，圆形无该上限。使用Clarabel SOCP、三个容差1e-9。无解时先最小化原单位下所有线性行的最大非负违反，再在最优违反加1e-8数值容差内最小化跟踪误差；加速度物理范数界不松弛。记录原约束违反和采样速度超限，不把最小违反解记unknown。连续速度屏障本身不保证有限步后速度范数界，若实际超限明确报告，不能假装已有全局离散安全保证。

门口状态为物理中心p与姿态theta，前视点q=p+0.025*(cos theta,sin theta)，用前向Euler独轮车p+=dt*v*(cos theta,sin theta)、theta+=dt*omega。约束在真实下一前视点q_next上计算h(q_next)>=0.9*h(q)；其他前视点固定于当前位置，双方半径各保守膨胀0.025，有限墙同样膨胀。真实中心碰撞另按原半径检查。速度与角速度界[-.26,.26]、[-3.8,3.8]。先将期望世界速度映射并裁剪到物理输入界，目标是在前视速度坐标下最小偏离该跟踪目标。SLSQP使用解析Jacobian、ftol1e-12、1000迭代，三个同问题初值（跟踪解、零输入、跟踪线速度配零角速度），从满足原约束的收敛解取最小目标值；验约束容差1e-7。局部数值解没有全局最优证书，这一限制必须报告；无有效解为unknown，不换控制器。

修正加在原期望速度上，然后重新跟踪和通过同一安全层。修正基使用第一次安全层对应的下一物理中心速度，仍用原位置和目标。两次投影都执行。逐机器人锥在加速度层或前视点速度层计算，使用实际活跃约束梯度，含物理输入边界；墙前陷阱与机器人间候选分开。直接静止判据固定为W=5秒内位移<物理半径且至少90%采样速度<=1e-3*vmax，未到达才计；它不是无限时域证明。约束违反与4a′重合另报。
