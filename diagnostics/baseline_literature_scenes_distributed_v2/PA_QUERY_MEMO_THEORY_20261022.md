# PA 精确查询缓存候选

历史依据为 PA_SAVED_QUERY_PROFILE_20261022.json、PA_QUERY_REUSE_PROBE_20261022.json 与 PA_QUERY_TEMPORAL_REUSE_PROBE_20261022.json。剖析显示底层原生搜索占主要时间；连续保存查询的 320 次原始搜索中，308 次具有相同充分状态键，路径后缀逐位相同。完整连续位置键没有命中。这些是只读查询证据，不是新增 rollout 或标签；采样潜力不作为生产提速倍数。

原始 astar_kernel_tiled.cpp 的连续起点只用于附近网格索引、初始节点的九条候选边、初始节点终点连接和返回路径第一点。初始节点之后的搜索使用网格坐标。长度大于一的预约路径第一点只用于时间零的边检查；后续时刻只读第一点之后的后缀。长度为一的预约路径会持续占用，因此完整保留。

键完整包含分辨率、分离距离、时域、墙与 margin、目标 float64 字节、全部预约长度、上述预约后缀、起始网格索引和十个初始判定位，并包含舍入模式、SSE 控制位及 x87 控制字。十个判定位直接调用与原始 C++ 相同的几何运算和判断。预约排列顺序保留。原始函数不使用 inner/outer；调用方始终传入原来的 0/+inf。

键相同则初始入队状态、第一次边通过/拒绝、之后全部节点的边判断、终点保持判断、启发式、序号与父节点搜索顺序相同，故原始路径后缀与无路径结果相同。缓存仅保存该后缀；返回时恢复本次真实连续起点的全部 float64 字节，包括有符号零。每次返回新数组，避免规划器修改缓存。这里没有在物理或控制器中量化位置。

未命中及不支持的输入继续调用原来封存的 astar_kernel_tiled.so。CBS 的有约束调用绕过该候选缓存。缓存为每进程最多 8192 项、估计内容最多 32 MiB，另有字典管理及构键的瞬时内存；容量淘汰和超大键不改变搜索结果。没有改分辨率、700 时域、搜索顺序、控制器参数、两次安全投影、修正基、种子、成功标准或统计预算。时间预算按仿真步数和节点计算，不按机器运行耗时判定。

现有门包括 656 次含预约的有限网格逐位比较、实际容量淘汰/超大条目回退、四场景 20 个保存查询的名义输出/路径/规划记录/证书比较。完整 episode 回放通过之前不启用生产。所有原始源文件和已封存证据保留，新候选以静态导入实现，不在运行时打补丁。
