## 1. Correct one-step statement

At fixed state `x`, random key `ξ`, and controller `c`, let `U(x)` be a nonempty closed convex CBF/speed feasible set and `Π` its exact Euclidean projection. Let `G_i` be the original bounded Goal row for robot `i`, `R_i` the original Rel row, and `a_i` the projected safe anchor. The frozen Perp row is

`B_perp,i = κ_B [a_i − Q_i a_i]`, where `Q_i = G_i G_iᵀ/(||G_i||²+ε²)`, `ε=10⁻⁶ V`, and `κ_B=3.303687238760696`.

For `η†=(0.5,−1/κ_B,0.55)` (inside the frozen box `[.5,1.25]×[−.5,.5]×[0,.75]`), **the exact identity** is

`a_s + Bη† = Q a_s + 0.5 G + 0.55 R`.

`Q` is the block diagonal map with rows `Q_i`. It is *not* the exact orthogonal projection `P_G` because of Tikhonov regularization. For nonzero `G_i`, `Q_i = λ_i P_{G_i}`, `λ_i=||G_i||²/(||G_i||²+ε²)<1`; for zero `G_i`, set both maps to zero. Thus `||Q a_s||≤||P_G a_s||=:d_c`. This corrects an exact-identity error without changing the frozen method. The bound can be conservative. If the actual source used a different regularizer or scale, the identity must be rechecked against that source; the current `shared_control/basis_families.py` matches it.

Define `v=0.5G+0.55R`, `u0=Π_U(v)`, and `u†=Π_U(v+Q a_s)`. Euclidean projection onto closed convex `U` is nonexpansive, hence `||u†−u0||≤||Q a_s||≤d_c`. Suppose a predeclared stage action set is `E_m(x)={u∈U(x): C_j(x)u≥b_j(x), j=1,…,J}` with finite nonzero rows. Put `r_m=min_j (C_j u0−b_j)/||C_j||`. If `r_m>d_c`, each row obeys

`C_j u†−b_j ≥ C_j u0−b_j−||C_j||·||u†−u0|| > 0`.

**PROVEN:** this certifies `u†∈E_m(x)` for that particular `(x,ξ,c)`. To claim a common `η†` on a class of controllers and states, the quantifier must be `for every (x,ξ,c) in the stated class, r_m(x)>d_c(x,ξ)` and `η†` must be admissible for every one. `r_m` is state dependent and controller independent only when `G`, `R`, `U`, and the stage rows are. `d_c` remains controller/key dependent. If `E_m` includes nonlinear inequalities, the corresponding signed distance or Lipschitz margin is needed; the displayed `r_m` applies only to the listed affine rows. Solver tolerances require a separate positive numerical allowance before an empirical row is called certified.

The exact single-step feasibility condition `A_c(x,ξ)∩E_m(x)≠∅`, where `A_c={Π_U(a_s+Bη):η∈Θ}`, is **PROVEN by definition** and says nothing about how to find a parameter. `r_m>d_c` is sufficient for this intersection through one fixed `η†`; its failure does not imply an empty intersection. A finite menu's failure does not rule out the continuous box. A reference action in `U` alone says nothing about whether `A_c` reaches it.

## 2. Time and stage logic

The one-step certificate has no invariant-set conclusion. A sufficient finite-step statement must separately verify, for every reached state and key: (i) the chosen action satisfies all safety rows and actual plant safety over the held interval; (ii) stage state constraints remain true until the declared guard is reached; (iii) a stage progress coordinate has a uniform lower bound `ν_m>0` while the guard is false; (iv) the guard transfers into the next stage's certified domain; (v) the remaining physical horizon, termination monitor, and final fractional step are compatible. Then at most `ceil((q_exit−q_start)/(dt ν_m))` held steps are needed, with the last step either shortened by an admissible action or handled by a guard crossing bound. A one-step `r_m>d_c` at the initial state proves none of (ii)–(v).

**FAILED counterexample to the tempting full-escape inference:** take a one-dimensional safe set `U=[−1,1]`, stage action set `E={u≥0.1}`, and a controller whose corrected action is `u=0.2` at `x=0` but `u=0` for all `x>0`; dynamics `x_{t+1}=x_t+dt u_t`, exit `x≥1`. The initial action has positive strict margin and satisfies the one-step condition, yet the trajectory stops after one step. No assumption equivalent to eventual escape is inserted to rescue the claim. At a stage boundary, the same issue appears if an action crosses the guard while leaving the next stage's domain; discrete overshoot and the remaining horizon matter.
