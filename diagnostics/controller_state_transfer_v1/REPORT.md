# 方法是否存在 state 条件化的泛化缺陷（2026-10-11）

**结论：在 Q 模式层面，没有发现方法缺陷；在选择层面，这个几何族无法评估。**
- **Q 模式层面：** 项目 critic 能从 24 个 state 学到 state×η 结构，迁移到留出几何，也能迁移到新 state 加新几何。效果与通用 MLP 和非学习的查表上界相当。
- **选择层面：** 从宽度 0.44 起，同一个固定 η（η2）对所有 state、两个 controller 的成功率都是 100%，按 state 自适应选 η 没有任何可得收益。按预注册规则，“方法缺陷已排除”这一条因此不能成立，原因是它包含的选择指标退化了，而不是检测到了缺陷。

## 设计与完整性

- **预注册：** 规则见 `PREREGISTRATION.md`，在任何 outcome 产生之前冻结。
- **场景与几何：** Toy Give-Way，只改变 `corridor_width`，共 8 个宽度：
  - 训练宽度：0.41、0.47、0.53、0.59；
  - 留出宽度：0.44、0.50、0.56（内插），0.62（外推）。
- **Controller：** `flow_isotropic`、`flow_anisotropic`（冻结的 Toy Flow 端点）。
- **η：** K8，取原 16 个候选中的索引 0、2、4、5、8、10、12、15。
- **State：** 24 个训练 state，另有 8 个全新 state，任何学习器都没见过。
- **复现门槛：** 在原宽度 0.40，与存档记录逐字节一致，共 12 次比对。
- **Rollout：** 共 13,312 次，全部 preflight→journal→merge 进 shared DB；postflight 全部为 exact reuse。0 次 numerical failure，0 次碰撞。

## 预注册指标结果（`results.json`）

m1 为 state×η 模式相关，括号内是 state bootstrap 的 95% CI；“上限”为信度上限（Spearman–Brown 校正后）。

| 集合 | ENT（项目 critic） | MLP | 查表（同一 state、最近训练宽度） | 上限 |
|---|---|---|---|---|
| T1：训练宽度 × 新 state | 0.60 [0.24, 0.87] | 0.73 | — | 0.68 |
| T2：留出宽度 × 训练 state | **0.88** [0.74, 0.94] | 0.86 | 0.85 | 0.78 |
| T2：外推宽度 | 0.76 | 0.69 | 0.73 | 0.48 |
| T3：留出宽度 × 新 state | **0.68** [0.33, 0.88] | 0.76 | — | 0.79 |
| T3：外推宽度 × 新 state | 0.64 | 0.76 | — | 0.47 |

- **D1（跨几何的 state 迁移缺陷）：** 不成立。ENT 在 T2 上 0.88，不低于查表的 0.85。
- **D2（几何内对新 state 泛化的缺陷）：** 不成立。T1 为 0.60。
- **D3（新 state 加新几何的额外缺陷）：** 按模式部分判断，不成立；T3 为 0.68，不低于 0.5 × T1。
  - MLP 被判为 D3，是因为规则里的选择部分：T3 的 matched − mismatched 恰好等于 0。但这是因为 oracle 的自适应增益本身就是 0，属于退化，不是 MLP 失败。
- **m2（交互幅度 skill）：**
  - T2 上 ENT 为 0.91、MLP 为 0.75。
  - 新 state 上很弱且 CI 很宽：ENT 的 T1 为 0.12、T3 为 0.21，MLP 为 0.33–0.34。
  - 即方向和模式迁移得对，但在只有 24 个训练 state 时，幅度校准受样本量限制。ENT 与 MLP 的 CI 重叠，看不出是表示特有的问题。
- **state 自适应选择：** 在所有留出宽度上，交叉拟合 oracle 的增益都是 0.000。在训练宽度 0.41 上为 −0.06，也没有正收益。选择层面的缺陷检验在这个几何族中**无法评估**。

## 与之前实验合起来看

| 已排除的方法缺陷候选 | 证据 |
|---|---|
| controller × η × 几何关系无法学习或迁移 | DB 宽度族 |
| entity 几何表示有缺陷 | DB 宽度族 |
| state × η 的 Q 结构无法学习、无法跨几何迁移、无法迁移到新 state | 本实验 |

**仍未检验：** 当不同 state 的最优 η 确实不同时（存在排序反转、有可得收益），critic 能否跨几何迁移这种 state 依赖的选择。这需要一个存在认证反转的几何族，例如 Ring 的 obstacle_radius 族（Ring 已有认证的 state/controller 排序反转）。

**附带发现：** 把 η 面板从 K4 扩展到 K8，加入 η2 之后，Toy 在宽度 ≥ 0.44 时被同一个固定 η 完全覆盖。这与审计中的发现一致：state 自适应选 η 的可得收益在这些面板上普遍很小，部署时的主要矛盾是场景级的 η 先验。
