`audit_inputs.py` 从副本读取冻结选择，对每个物理状态、学习型规划器、部署口径要求恰有一条标签。两批测试各有1,152条冻结学习策略标签，并保留目标右侧规则、安全投影和纯名义动作三个内部参照。第二批文件还混有单机记录，已按实际字段排除；绕场景中心的规则不进入本轮比较。逐条筛选结果见 `FROZEN_HISTORICAL_LABELS.json`，目前仅作待核对证据，尚未声称完成前缀等价认证。

## 仍需补齐的证据

1. 论文端口异常分型、与作者来源对应的修复、训练试跑及单机适用性门。
2. 基准甲共同物理环境的200局核对、冻结学习方法至少64局复演与历史复用前缀核对。
3. 旧评估 JSONL 本身只有结局标签，没有完成时间、逐步轨迹或计算时间字段。须继续检查其他保存产物；缺失指标不能由成功标签推算，也不能编造旧轨迹。
4. 场景状态0–11的生成器逐位复现，以及满足协议条件后的新状态12–19。
5. 对称的两轮训练调参、饱和曲线、测试前的参数与分析冻结，以及之后的新测试。

旧论文记录的诊断允许复用；修复后的正式外部方法 rollout 不复用修复前成绩。基准甲已有学习方法不重训、不改权重，不因更换评估适配层丢弃兼容结局标签。

## 保护与仓库事实

正在运行的四系数以内删减实验已登记为并行目录。下一轮准备进程只对该目录作元数据审计，不读取文件、不计算哈希；其现有执行代理继续在原任务权限下监控当前任务。新目录的保护钩子禁止访问并行任务内容，写入限定于本轮目录和本轮官方 journal。

用户已明确解决Git指令冲突：允许建立独立分支、仅提交新实验目录，见 `USER_CLARIFICATION.json`。为保持当前任务的分支与收尾记录，分支切换留到当前任务交付后。

主仓库的只读Git快照已保存，并排除并行任务目录。指定PoC路径实际没有`.git`元数据，`git status`返回“not a git repository”；没有把它伪装为干净仓库。该路径仍只读，任何实际导入文件另核对哈希，此项限制记录在 `INTEGRITY_START.json`。
