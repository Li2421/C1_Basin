# 修正列与文献约定

本轮是按用户给定定义实现的协调机制实验，不是下列论文的完整复现。冻结的名义控制器、两次安全投影、几何和任务判据均保持原执行语义。机制相似不能替代论文原方法的对照结果。

| 本轮控制项 | 对应的文献动机 | 对应边界与是否新增 |
|---|---|---|
| 目标侧向旋转 | Wang、Ames、Egerstedt，2017，空间上保持一致的扰动约定：[作者版](https://liwanggt.github.io/files/A2_Safe_Swarm.pdf) | 复用旧字典列。本列是目标方向旋转，不声称实现该论文完整死锁消解方法。正系数沿旧实现为逆时针；菜单同时含正负值。 |
| 等待方减速 | Chandra 等，社交小游戏中的速度协调：[论文](https://arxiv.org/html/2508.13459v1)、[项目页](https://socialminigames.github.io/) | 本轮新增。对完整投影前输入乘以常数；不能将“自身输入减半”与“速度不超过通行者的一半”视为同一约束，最终安全投影也可能改变速度方向。本实验只执行用户规定的乘性修正。 |
| 每通道先到先得、方向持有与预约表 | Dresner 与 Stone，2008，路口预约：[作者版](https://www.cs.utexas.edu/~aim/papers/JAIR08-dresner.pdf) | 本轮新增局部时间约定。原说明是方向状态机，续接预约方案登记进入/离开时刻；均不是原论文完整路口协议，也不引入硬排程约束。 |
| 一批同向者先过、清空后再反向 | Li 等，2021，走廊对称推理：[论文](https://arxiv.org/abs/2103.07116)；Ni 与 Ye，2026，组级走廊推理：[论文](https://ojs.aaai.org/index.php/AAAI/article/download/40205/44166) | 本轮新增。离散路径规划中的对称破除提供分组时间约定的动机；其完备性、最优性结论不转移到本系统连续速度控制器。 |
| 出口净空、通道内逆向者退出、等候点 | 用户原说明与续接说明的明确局部几何规则 | 本轮新增，不能冠以某篇论文的原方法名称。状态机允许修正已到终点的出口占用者，但不更改成功判据，也不保证最终投影后严格静止或退出。 |
| 整队让行 | 原字典活跃机器人对的角色定义，加用户规定的迎面角度筛选与接触图传播 | 本轮新增，不依赖通道识别；不使用未来标签选择角色或队伍。 |
| 朝目标、互斥分离、局部净空梯度 | 旧生产字典与既有实验定义 | 原样复用，分别保留其原尺度、归一化、裕量和退化处理；本轮不重新构造这些列。 |

背景提及的 [LiveNet](https://arxiv.org/abs/2412.04659) 仅用于相关研究定位，本轮不运行学习策略，也不借其结果推断当前多机器人队列的能力。“Zhou 等 2017”在给定背景中未唯一定位到文章，未把它作为任何本轮公式或实现的来源。

窄门每侧三台的 39.3 秒专家数值轨迹来自旧 `zero_coverage_audit/`。当前代表场景每侧四台的约25–30秒通行时间是规划背景中的粗估；没有实际见证前，不据此宣称联合可解或时限内可解。有限候选搜索耗尽也不证明几何不可达或连续参数空间不可能成功。
