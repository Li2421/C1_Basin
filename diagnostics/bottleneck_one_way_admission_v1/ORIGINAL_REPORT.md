# 通道单向放行验证

主族在当前冻结的40个困难案例上，Oracle@16 / @32 / @64 已验证覆盖为 20 / 31 / 33；全部272案例上的Oracle@16当前为217/272，原四列为183/272。未完成项不能视为失败。逐类型见下表。

四列族为朝目标、互斥分离、目标右侧旋转、局部净空梯度；主族在其后加入等待方减速、等待方让出出口、通道内逆向者退出，并维护每个通道的通行权。它含状态与乘性减速，本轮不把它称为固定线性五维基，也不选择维度。

名义控制器为集中式随机采样模型预测控制、梯度下降模型预测控制；沿用原两次安全投影、动力学、路线引导和时限。目标右侧旋转沿用历史命名，原字典正系数实际为逆时针，负系数为顺时针；未改变其实现。修正族和角色重分配定义见冻结输入说明。
