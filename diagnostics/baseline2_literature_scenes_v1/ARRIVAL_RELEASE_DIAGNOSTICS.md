# 已到达机器人是否被集中式安全投影移动

只读取窄通道场景原始state0的只加安全投影轨迹，逐个检查初始已在目标容差内的机器人。名义输入在到达停止之后确实为零，但它们仍是联合安全投影中的决策变量。此检查是描述性的执行语义证据，不是新增成功终点或死锁因果证明。

因此，流程版不能等同于把已到达机器人固定成静态障碍的去中心化控制。中央投影本身可能分配退让运动；它与动力学、安全层替换共同限制论文版死锁证据向流程版的解释。所有实例、seed与机器人数据见CSV/JSON，白盒单列而不进入迁移主结论。
