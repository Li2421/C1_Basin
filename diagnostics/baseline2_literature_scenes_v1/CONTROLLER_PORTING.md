# Controller移植

48个实例、8个类型的参数逐项来自CONTROLLER_MANIFEST.json与历史ZOO_MANIFEST.csv。旧能力标记仅作来源记录，新场景能力以本轮单机器人>=95%为准。所有新类均在本轮目录；旧源码、超参数、冻结checkpoint与默认安全配置未修改。

|类型|几何/机器人数适配|保留的算法|
|---|---|---|
|分布式模型预测控制（distributed_shooting）|任意N逐机rollout、实际几何与速度上限|原分布式shooting、名义/零候选、时域/样本数/碰撞权重|
|集中式随机采样模型预测控制（centralized_sampling）|联合动作维数2N与新墙代价|原shooting、名义/零候选、时域/样本数/碰撞权重|
|交叉熵方法模型预测控制（cross_entropy）|将固定四机动作shape改为N，圆环代价改为本场景墙净间隙|原3段knots、采样数/迭代数/时域、精英10%、均值方差更新与返回样本|
|优先级时空A*规划（prioritized_astar）|固定环形边界替换为任意有限线段接口，实际N与物理速度作为输入|原分辨率、重规划间隔、优先顺序、700层搜索、跟踪规则|
|分布式交叉熵方法模型预测控制（distributed_cross_entropy）|逐实际机器人读取其他者的coast预测与新墙代价|原逐机fold_in、3段knots、采样/精英/迭代参数|
|集中式模型预测路径积分控制（centralized_mppi）|联合动作维数2N与新墙代价|原样本数/时域/温度、softmax加权和warm-start平移|
|梯度下降模型预测控制（gradient_mpc）|实际N与墙代价；无配对时空集不取空均值|原3结点插值、Adam、迭代数/学习率、warm start、自定义范数导数、JAX float32|
|冲突搜索多机规划（conflict_based_search）|任意N与墙段接口，位置/预约/负约束原样|原冲突树、预算、分辨率、单机搜索与跟踪规则|
