# 结果前封存的统计定义

所有19类型均为开发证据，类型内controller等权、其内state等权，q0/1同簇。主区间5000次配对分层bootstrap，依次类型、controller、state重抽；单类型只重抽其controller和state。unknown主值为0，并给unknown上界；配对动作UID相同的unknown不引入差值不确定性。

方法名与顺序严格见menu_c6.METHODS。七组差为(0−7,0−6,1−0,2−1,0−3,1−4,1−5)。安全投影分组由新评估的每controller 24×2条成功率下界确定，≥.98、[.90,.98)、<.90，固定为描述性分组。族与探测早/晚/无停滞、η距离分组按封存的PROBE_FEATURE_DEFINITION.json；距离无法实现/读取时明确缺口，不虚构重查η。

伤害沿用前轮定义：每controller成功率下降至少10个百分点；同时报告在线触发相对第一层、相对安全投影两种伤害数。T2高安全投影组要求在线触发相对第一层差点估计≥0，且相对安全投影伤害数为0；低安全投影组要求在线触发相对第一层差CI下界>−1pp。T6以点估计是否≥90%逐学习型类型判断，同时附CI；不做最终3未见类型评估。

全局触发设置只在外层源类型的内部留一类型预测上，从三个设置选取：只看已标训练动作槽中的允许动作，q0真实选中动作成功下界类型等权最大；unknown计0并另报未评分比例，平手优先较小未评分比例，再按敏感、中等、保守顺序。稀疏训练支持验证明确标注为53槽内验证，不冒称新全菜单覆盖。

类型信息参照只允许同state的完全相同物理动作（包括完整浮点η、阈值、触发、重查策略及执行版本），禁止跨state按提议序号对齐；留出controller的任何副本一律不作donor；已有动作未评分与donor支持单列，不用模型预测补标签。
