# 计时试跑

对每个不超出训练范围的留出场景，使用一个既定合格控制器、两个状态与场景级提案0/1；优先冲突搜索多机规划（conflict_based_search），否则既定顺序首个类型。相同请求按UID去重，精确缓存直接复用。

正式缺失请求预测合计3.09单CPU小时；并行墙钟不能由均值可靠推出，优先级时空A*规划的尾部可能主导。
