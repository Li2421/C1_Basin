# 排序诊断

同格排序准确率：在同一状态和控制器下，对全部成功/失败候选对计算成功者分数较高的比例，并列计一半；仅计成败都有的格子，场景内格子等权，再按场景等权。场景Spearman比较候选场景分与真实类型等权成功率。应用状态级打分退回；场景级退回仅决定执行选择。
