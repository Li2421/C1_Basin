# Round18 预标签析因解释澄清

任务书模型表固定 C0 训练于 Round15，C1 训练于 Round15+Round17+TRAIN-new，C3 训练于 Round15+Round17，C2 训练于 Round15+Round17+TRAIN-new。这些数据集合必须原样执行。由此，**C1−C0 同时包含 Round17 与 TRAIN-new 的覆盖变化，C3−C0 同时包含 Round17 覆盖与表示变化**，不能单独解释为纯覆盖或纯表示效应。对于严格保持另一因素相同的描述性对照，C2−C1 隔离新增 η2 表示，C2−C3 隔离 TRAIN-new 覆盖；其余两项仍按任务书报告并注明混杂。

本澄清在任何 Round18 新成功标签之前写定，不更改模型表、训练集、阈值、主要或次要判定。
