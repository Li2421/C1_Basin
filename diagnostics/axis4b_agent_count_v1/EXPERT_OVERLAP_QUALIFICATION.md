# 同轮专家填充尾部空闲

全部 round32–35 已完成，当前仅 round36。本轮专家是预注册的每 N 32 个固定评估 state 各一次，不依赖 controller 能力门、不参与源选择或 critic 训练。允许在本轮 pilot 尾部已分配完全部案例、且用户总计 CPU 分配低于18时，将原定 expert 阶段提交到空闲槽。专家始终使用原冻结 runtime 和原 worker，参数、state、身份、horizon、执行、journal 与官方后续 merger 均不变。不提前读取专家标签用于 controller/迁移选择。

新的资源监控只改变各本轮数组的配额：每数组最多获得18减去其他任务已分配 CPU 的余量；没有余量时 hold 其未启动案例。外部任务突增时仍只暂停本轮进程组并保留现场。原 pipeline 最后等待已提交的专家作业并执行同一单进程官方 merger，不重复提交。专家预先登记/preflight早于提交，源码只读与所有旧冻结 hash 保持。

该操作提高长 pilot 尾部的 CPU 利用率，不跨轮并行、不增加实验、也不根据结果选择或调整任务。
