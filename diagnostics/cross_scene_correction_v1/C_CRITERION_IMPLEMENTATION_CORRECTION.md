# 丙的判定文字与实现核对

原说明第五节写：主模型相对交叉拟合最优的“平均落后，不比按场景低成本校准多5个百分点以上”。甲、乙明确写95%区间在零以上，丙没有另写区间门槛。最初代码额外要求丙差值的95%区间上界≤0.05，比原文均值要求更严格。

在主模型尚未拟合、未计算或查看丙结果、尚无外推评估结果时，默认按原文落实均值差≤0.05，并同时报告完整95%区间以及更严格的区间上界检验，不将新增条件冒充原预登记要求。已异步询问用户是否本意为更严格规则；若用户在模型冻结前明确指定区间规则，记录明确回复及时间。未收到回复不视为批准修改原文。

两种谓词在代码中分开，所用规则及说明收据将在MODEL_FROZEN中封存；平均差为(calibration−ridge)，因为两者相对同一交叉拟合基准的落后相减后基准抵消。甲、乙、丁、0.05阈值、标签、模型、调参与自助法均保持原要求。回归检查覆盖“均值0.04、区间上界0.10”这一能区分两种判定的例子，避免将两者混为一谈。
