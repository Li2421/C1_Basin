## Executive result

The pilot does **not** support the projection cone as a control-discriminative
risk field. In the exact old 108-pair TEST-Q panel, primary Pi_2 `R_cone`
changed for 108/108 action pairs, while empirical frozen continuation risk
changed for 0/108: every one of the 27 arms again had `Q_D=8/8=1`. The
executed actions remained distinct for 108/108 pairs, so this is not mass
projection aliasing.

There is also a structural geometry warning. Across all 127 scored P/Q
state-actions, no drive lay inside its joint-R4 active safety cone. Thirty-eight
had an empty active set and the other 89 were outside a proper cone; observed
cone ranks were only 0--3. Thus the predeclared signed margin never exercised
its negative, inside-cone branch and reduced on this panel to minus an outside
distance. Its strongest associations were with `||u_safe||` and progress
speed, not active-constraint count.

The old Q panel is outcome-saturated, so it cannot estimate a nonzero ordering
effect or prove global impossibility. The correct final classification is
therefore **CASE E — INCONCLUSIVE**. It is nevertheless decisive for the
predeclared pilot gate: do not advance this score to `G_phi`, do not tune it,
and do not run the gated gradient/escape intervention experiment from this
evidence.

## Exact frozen projection formulation

Let the joint action be

\[
u=(u_{0x},u_{0y},u_{1x},u_{1y})\in\mathbb R^4.
\]

Both projection stages solve the same state-dependent convex problem with a
different input `y`:

\[
\Pi_{\mathcal U(x)}(y)=\arg\min_u\frac12\|u-y\|_2^2
\quad\text{s.t.}\quad Au\ge b,\qquad
\|u_a\|_2\le s_{\max},\ a\in\{0,1\}.
\]

The stages are:

| stage | projection input `y` | output `p` |
|---|---|---|
| Pi_1 | `u_flow` | `u_safe` |
| Pi_2 | `u_safe + r` | `u_exec` |

The matrix has 17 rows. Row zero is the genuinely joint pairwise constraint.
For `d=x_0-x_1`,

\[
h_0=\|d\|^2-d_{safe}^2,\quad
A_0=[2d^\top,-2d^\top],\quad b_0=-\gamma h_0.
\]

The remaining 16 rows are eight finite wall segments per agent. If `q_aj` is
the nearest point on segment `j`,

\[
h_{aj}=\|x_a-q_{aj}\|-r_a-r_w-m_w-10^{-4},\qquad
\nabla_{x_a}h_{aj}=\frac{x_a-q_{aj}}{\|x_a-q_{aj}\|},
\]

and the gradient occupies only agent `a`'s two-coordinate block, with
`b_aj=-gamma_wall h_aj`. Therefore wall rows are block-local but the pair row
couples both agents; the overall projection cannot be decomposed into two
independent 2-D projections. `gamma=gamma_wall=1` and `s_max=0.5 m/s` are
frozen.

The implementation uses SLSQP linear QPs and adaptive *outer* supporting
planes for the two Euclidean speed balls. An accepted solution that lies in
the balls is the solution of the stated exact convex problem to the declared
tolerances; there is no post-solve clipping. The direct feasible fast path
returns `y`. The numerical tolerances are:

| item | value |
|---|---:|
| linear active set | `1e-7` |
| primal feasibility | `1e-9` |
| KKT optimality/complementarity | `2e-6` |
| speed feasibility | `1e-10` |
| SLSQP `ftol` | `1e-12` |

The solver does not persist dual variables. This audit reconstructed
nonnegative multipliers by NNLS on the active exact Jacobians. Across 254
audited stages (Pi_1 and Pi_2 for 127 records), maximum linear violation was
`6.12e-17` and maximum stationarity infinity norm was `1.35e-7`; no speed ball
was active. The exact machine-readable formulation is in
`data_v1/projection_formulation.json`.

## KKT derivation

Using the implementation's greater-than orientation, define

\[
g_i(u)=A_i u-b_i\ge0,\qquad
q_a(u)=s_{\max}-\|u_a\|\ge0.
\]

With nonnegative multipliers `lambda_i,mu_a`, the Lagrangian is

\[
L=\tfrac12\|u-y\|^2-\sum_i\lambda_i g_i(u)-\sum_a\mu_a q_a(u).
\]

At `p=Pi_U(y)`, the exact KKT system is

\[
\begin{aligned}
&p-y-A^\top\lambda+
  \sum_a\mu_a E_a^\top\frac{p_a}{\|p_a\|}=0,\\
&Ap-b\ge0,\quad s_{\max}-\|p_a\|\ge0,\\
&\lambda_i\ge0,\quad\mu_a\ge0,\\
&\lambda_i(A_i p-b_i)=0,\quad
  \mu_a(s_{\max}-\|p_a\|)=0.
\end{aligned}
\]

Consequently,

\[
y-p=-A^\top\lambda+
\sum_a\mu_aE_a^\top\frac{p_a}{\|p_a\|}.
\]

This sign is important: when speed constraints are inactive, the projection
residual `y-p` lies in the cone generated by **`-A_i^T`**, not by `+A_i^T`.
The three objects kept distinct throughout are:

- projection residual: `y-p`;
- nominal/control drive: `y`;
- executed velocity: `p`.

Near an exact stall `p=0`, inactive speed balls give
`y=-A_active^T lambda`; only then does the *drive itself* lie in the blocking
safety-normal cone.

## Projection-KKT tautology audit

| class | quantity | audit |
|---|---|---|
| A | `p-y` in the cone of active feasible-set Jacobians | Automatic for every certified Euclidean projection. Not deadlock information. |
| A | `y-p` in `cone(-A_active, +speed radial normals)` | The same KKT identity with signs reversed. Not a risk score. |
| B | `y in cone(-A_active)` when `p=0` | Special to exact zero output (and inactive speed balls); it is not true for a generic projection. |
| C | ambient signed distance from `y` to the boundary of `cone(-A_active)` | Additional facet/rank geometry away from exact stall. |
| C | cone rank, lineality, full-space status, nearest-facet multiplicity | Additional active-normal geometry. |

There is an important A/B-derived bound. If speed balls are inactive, KKT
gives `c=y-p in C`, hence

\[
\operatorname{dist}(y,C)\le\|y-c\|=\|p\|.
\]

Therefore the outside-cone distance can become an executed-speed proxy even
though it is not itself a KKT identity. This is exactly the regime encountered
in the pilot.

## Definition of `R_cone`

For stage `k`, let the active safety set be

\[
I_k=\{i:A_i p_k-b_i\le \tau_{act}\},\qquad
C_k=\operatorname{cone}\{-A_i^\top:i\in I_k\}\subset\mathbb R^4,
\]

with certified feasibility understood and primary `tau_act=1e-7`. Actuator
normals are audited in KKT but are not silently redefined as safety forces;
any speed-active record would be tagged `speed_confounded`.

For the ordinary ambient topology, the predeclared margin is

\[
M_{cone}(y,C)=
\begin{cases}
\operatorname{dist}(y,C), & y\notin C,\\
0, & y\in\partial C,\\
-\operatorname{dist}(y,\partial C), & y\in\operatorname{int} C.
\end{cases}
\qquad R_{cone}=-M_{cone}.
\]

Thus margin is positive outside, zero on the boundary, and negative inside;
risk has the opposite sign. This is not ordinary distance-to-cone, which would
erase all interior depth.

Degeneracies are explicit:

- Empty active set: `C={0}`. A nonzero drive is outside; this is tagged
  `empty_active_outside` and is not interpreted as safety confinement.
- Proper low-dimensional cone: its ambient interior is empty, so every member
  is an ambient-boundary point with margin zero. No relative-interior convention
  is introduced to manufacture negative values.
- Non-pointed cone: lineality dimension is reported and the same ambient
  definition is used.
- Full-space cone: `C=R4` has empty boundary; margin/risk remain extended-real
  `-infinity/+infinity` rather than receiving an arbitrary finite constant.
- Zero rays are removed at `1e-12`; membership and facet tolerances are `1e-9`
  and `1e-10`.

## Pi_1 vs Pi_2 choice

Pi_1 is attractive conceptually because its cone is defined before a future
`G_phi` acts. But in a same-state action-intervention test, neither `u_flow`,
`u_safe`, nor the Pi_1 active set changes. It produced 108/108 score ties in
the old Q panel and therefore cannot rank residual actions by construction.

Pi_2 reflects the geometry that actually determines `u_exec`, so it is the
scientifically defensible candidate for the present action-level question. Its
drawback is real: `y_2=u_safe+r`, its active set, and its cone all depend on the
residual being evaluated. It is consequently piecewise-defined and can switch
cones as `r` changes. Pi_2 was declared primary, and Pi_1 secondary, in
`predeclared_protocol.json` before outcome scoring. No choice was made after
seeing TEST Q.

## Minimum-change escape audit

Only the geometry was derived; outcome rollouts were gated off. For a frozen
proper full-dimensional cone represented by inward unit facet normals
`C={v:n_f^T v>=0}`, an interior drive has nearest-boundary candidates

\[
\delta_f=-(n_f^\top y)n_f
\]

for every nearest facet. Strictly leaving a closed cone is an open condition,
so without a separately justified clearance its optimum is an infimum attained
on the boundary, not a strict-exit minimizer. With a physical clearance
`epsilon`, the corresponding candidate is
`delta_f(epsilon)=-(n_f^T y+epsilon)n_f`; no epsilon was introduced here.

Other cases are not assigned arbitrary directions:

- If `y` is outside, the minimum frozen-cone change is zero.
- If `y` belongs to a proper low-dimensional cone, every member is already on
  the ambient boundary; arbitrarily small components in `span(C)^perp` escape,
  giving zero infimum and generally infinitely many directions.
- For an empty active set, `C={0}`; a nonzero drive is already outside.
- For `C=R4`, no cone escape exists.

Compatibility with hard safety means evaluating
`p'=Pi_U(y+delta)`. Since 104/108 Q pairs changed active set, a frozen-cone
escape would require cone recomputation and a self-consistency check after
projection; merely crossing the old cone boundary is insufficient. All 127
observed commands were already outside, so the direct construction would
return zero at the frozen-cone level and supplied no nontrivial tested intervention.
The machine-readable derivation is in
`data_v1/minimum_change_escape.json`.

## Multimodal and symmetry audit

The joint cone contains no chirality or agent priority. At a symmetric
head-on, pairwise-only state it is a rank-one ray in R4. Its three-dimensional
normal complement supplies a continuum of arbitrarily small escape directions,
including mirrored left/right and alternative give-way modes. Multiple nearest
facets likewise yield a set of equal minimum-change candidates. A scalar
gradient can be zero, undefined, or select one branch discontinuously at such
symmetry/facet-switching points.

No `agent A yields`, left/right, or clockwise convention was added. Zhang et
al.'s optional reference direction would be an extra coordination convention,
not a consequence of this frozen projection. The set-valued geometry is
conceptually compatible with a future multimodal generative controller, but
this audit provides no `D_H` reduction evidence for training one.

## Failure cases

- **No dangerous interior observed:** 0/127 drives were inside or on the
  boundary; the signed interior depth was never exercised.
- **Low-dimensional/empty geometry:** ranks were 0--3 in R4, including 38
  empty active sets and 19 rank-deficient multirow sets.
- **Speed-proxy collapse:** outside distance obeys
  `dist(y,C)<=||u_exec||` and correlated strongly with low speed/progress.
- **Action-outcome saturation:** all 27 Q arms were deadlock 8/8, leaving no
  true-risk ranks and wide per-arm confidence intervals.
- **Active-set/cone switching:** 104/108 Q pairs changed both, so local smooth
  scalar geometry is not the dominant regime.
- **Nonsmoothness:** empty-set transitions, active-set changes, and nearest
  facet ties imply discontinuity or piecewise differentiability; gradient
  qualification was correctly gated off.
- **Symmetric escape multiplicity:** lower-dimensional symmetric cones produce
  continuum-valued, zero-infimum exits rather than a unique control.
- **No mass aliasing:** all executed-action pairs stayed distinct, so
  projection cannot be used as an unsupported explanation.
- **Possible switching behavior:** A-B-A flags were observed, but the frozen
  first-event records cannot establish post-stall livelock and `D_H` was not
  relabeled.

Relative to the old risk, the failure is more basic: old `R_risk` was an
excellent precursor but lacked control consequences; the present score was not
a stable early predictor, did not access its intended interior geometry, and
still produced action score changes without any observed Q change.

## No-parameter-fishing audit

The active tolerance was predeclared at `1e-7`. The only sensitivity values
were one decade either side: `1e-8`, `1e-7`, `1e-6`. All three produced exactly
the same 108 score-different pairs, 0 true-risk-different pairs, 104 active-set
switches, 0 aliases, and identical score/effect summaries. No physical
lookahead or score-shaping parameter was introduced. This sensitivity changes
neither true control discrimination nor the decision.

## Final CASE A/B/C/D/E

**CASE E — INCONCLUSIVE.**

Reason: the primary score failed the frozen Q qualification, but all Q arms
were saturated at 8/8 deadlocks, so the panel has no true-risk rank variation
and limited power to distinguish a universally bad ordering from an
intervention budget that is uniformly ineffective. Simultaneously, the actual
joint-R4 cones were always empty/lower-dimensional with every tested drive
outside, so the proposed interior signed margin was not exercised. There is no
implementation uncertainty in the projection sign/KKT reconstruction, but
there is insufficient causal and geometric support for a positive method
claim.

Operational decision: stop after the CPU pilot. Do not train `G_phi`, tune or
soften `R_cone`, change thresholds, or run gradient/minimum-change outcome
experiments on this basis. A future audit would need a separately predeclared,
non-saturated action panel with enough true `Q_D` variation; that is a new
experiment, not a continuation justified by the current score.
