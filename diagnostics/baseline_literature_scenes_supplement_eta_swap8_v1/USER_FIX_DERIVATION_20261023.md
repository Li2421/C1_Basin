这是用户指出说明设计错误后的修正，不是看结果调参。仅移动障碍约束及静态布局改变；原结果保留标“原约束/原布局（作废）”，不进主分析。碰撞判据、成功标准、95%能力门、控制器算法/超参数、state/seed、采样物理、修正基及Rc、感知范围和无解回退都保持。free和旧场景执行身份保持，当前旧评估作业未中断。

## 移动约束与全区间推导

机器人半径r=.05，障碍半径r_o=.3，pair d_safe=.1001，epsilon=.01*d_safe=.001001m，D=r+r_o+epsilon=.351001m。删除原.0125m一步半径膨胀。令帧首d=p−c、n=d/||d||、g=||d||−D。新行：

n·u >= vbar − (gamma/dt)g，vbar=.25m/s，dt=.05s。

只用已声明的速度上界，不使用障碍实际速度、未来路径、waypoint或控制器输出。证明固定帧首n。帧内tau∈[0,dt]，机器人p(tau)=p+tau*u；障碍位移Delta c(tau)的范数≤vbar*tau（本轮分段waypoint运动满足，即使一步内转折亦成立）。因此

||p(tau)−c(tau)|| >= n·(p−c+tau*u−Delta c(tau))
                         >= D+g+tau*(vbar−gamma*g/dt)−vbar*tau
                         = D+(1−gamma*tau/dt)g >= D。

最后一步需要g>=0与gamma<=1。故下一采样点和全部帧内时刻均不重叠，还保留epsilon；这个界也给出下个采样点g_next>=0，可从满足前提的初态归纳。任意时刻约束未被满足（无解后的违反/数值失败）时不冒充该保证。

感知范围仍.5m。范围外且原速度球满足时，最大相对一步位移(.5+.25)*.05=.0375m，因此距离下界>.4625m>D；范围外到范围内的第一步同样安全。速度球被无解回退放松时，这一范围外补充界不适用，放松/违反仍逐步记录，不能宣称全局可行或把约束违反当unknown。
