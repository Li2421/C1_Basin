# 移动障碍碰撞：保存轨迹核查

用户询问碰撞是否发生在安全过滤之后及其原因。以下仅读取保存证据，没有新rollout，没有改控制器、安全层、物理或判据。

是：执行链swap_runtime.py:27与32先后调用两次安全投影，执行第二次投影输出。本批能力门是单机器人η=0，没有correction；两次投影目标相同。投影会保留它认为已经可行的名义速度，这仍是通过过滤器，而不是绕开过滤器。

当前移动约束位于swap_safety.py:26–30。令d=p−o、h=||d||²−D²，D=.3+.05+.0125+.0001=.3626m。它要求2d·u≥−γh，γ=1，按当前位置把障碍当静止；真实相对运动则有h_dot=2d·(u−v_obstacle)。当前约束没有障碍速度项，也没有在导数中使用速度上界的最坏接近项。

额外.0125m是一帧(.25m/s×.05s)的位移余量。若帧首位于膨胀安全集外，静止障碍约束结合该余量能保护这一帧真实物理间距；但下一帧只保证物理间距，不保证仍在膨胀安全集外，障碍持续接近会消耗余量。进入膨胀层后，当前CBF允许缓慢恢复间距，未要求赶上移动障碍的接近速度。因此即便QP约束满足，也可以发生连续扫掠物理碰撞。

具体证据MOVING_COLLISION_EXPLANATION.json：centralized_mppi4，state10，solo agent5，seed0，t=4.15s（第83个零基step）。

- 两圆真实安全中心距.35m；帧首.351659m，仍有1.659mm净空，但已在.3626m膨胀安全集内。
- 过滤后机器人径向远离速度.078207m/s；障碍径向接近速度.236957m/s。
- 当前静止障碍CBF约束余量+.047190，QP认为可行，动作未改写，第二次投影与第一次一致。
- 真实移动障碍对应的h_dot+γh为−.119466，实际间距正在快速减少。
- 50ms后中心距.343752m，实际重叠6.248mm。保存轨迹的连续扫掠计算与此重算逐值一致；不是漏检一步后的额外仿真。

MOVING_CAPABILITY_COLLISION_AUDIT.json汇总全部24576个moving单机请求：19052成功，4448移动障碍碰撞，1076超时；4448碰撞均未记录约束违反、无解回退或速度超限。这不能由QP无解时牺牲配对/障碍约束解释；上面的保存轨迹展示了当前运动模型允许的碰撞机制。

结论限定于本轮这套“当前位置静止处理+一帧半径膨胀”的SI安全层。它不是对非零η correction的效果检验，也不是对原HJB-GNN学习控制器的复现实验。当前实验按已冻结协议继续，moving能力门0合格导致correction评估缺口，不据这些结果私自修改约束。
