# Frozen fitting protocol

See `protocol.md`, `cv_folds.json`, `oracle_budget_subsamples.json`, and `oracle_revision.json`. Three scenario-stratified outer folds were used. Per-state theta used the same V1 sequential robust-anchor procedure in both scenarios with nested16/24/32 labels. Global exponent, erosion, and piece count were selected only on development states. A48-label diagnostic tested oracle heaviness without altering the primary gate.
