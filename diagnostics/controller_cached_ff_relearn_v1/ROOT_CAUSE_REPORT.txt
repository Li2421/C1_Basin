CONTROLLER / STATE-CONDITIONED Q 根因报告
日期：2026-10-09
当前总体 verdict：CROSS_SCENE_STATE_CONDITIONING_NOT_ESTABLISHED

结论边界
controller 与 Q 的关系确实可以学习，已有未见 physical states 和同场景未见 analytic controller 的证据。尚未建立跨场景的 state-conditioned eta selection。不能把 selection success 的上升当作 Q 关系迁移的证明，也不能把当前失败解释成理论上不可能。
本轮按用户最新要求只保留根因判别；contrast-loss 拟合已取消。未继续做正则化、温度、学习率、网络容量等性能调优。未启动新的 controller-family rollout batch。

1. 已确认的输入根因：旧 H20 的 controller 归属错误
旧 field_pipeline_v1/learn.py 的 NOMINAL_CACHE key 只有 (scenario,state_uid,probe_root)，没有 controller。在同一进程先计算 base、再计算 held 时，held 的 nominal H20 使用了 base 的轨迹。
108 个 source states 中，96 个 states / 768 个 state–eta 配对出现相同 nominal prefix；另12个 states 的 prefix 随 controller 改变。这形成了不一致的输入定义。
在预先指定的一例 TRAIN state 上，实际复算逐值复现旧缓存；清理 controller 缓存后，24个通道中13个改变，最大绝对差0.75。Q16 success labels 没有被污染，错误在 critic input。
修复通过 controller-scoped cache adapter 提供，真实双-controller regression 已通过。旧研究文件及原始证据保持原样，禁止继续把未修正的 H20 context 当作正确的 controller-specific 特征。新 static-query critic 完全不使用 H20 或这个缓存。
补充完整性核查：原先正确的12个states/96个state–eta配对，重建后的nominal prefix逐值不变；原先串controller的96个states/768个配对全部需要修正。因此不是因为换了精度或执行pipeline才得到不同输入。

单因素隔离：旧80 TRAIN/28 VAL、相同Q16 labels、相同架构、optimizer、1600步上限和VAL-NLL选择规则；仅修正 nominal 的 controller 归属。末态距离通道无法从旧摘要重建，因此在两个对照中都去掉该一个通道。修正其余相关差值。三训练seed的等权ensemble，在旧16-state诊断集上：
                             原缓存        controller归属修正
Q probability MSE            0.06201       0.05453
controller delta MSE          0.09010       0.07307
eta-centered delta corr       0.38557       0.54995
Q MSE reduction：0.00747，95% CI [0.00318,0.01196]。
Controller delta MSE reduction：0.01703，95% CI [0.00144,0.03298]，相对下降18.9%。
这是该输入缺陷对失败有实际贡献的受控证据；不是“它解释了全部剩余误差”的证据，也不是新的H20最终方法。CI以physical state为单位，条件于这三次拟合及两种controller。

2. 已确认的信息根因：当前动作/当前分支不代表完整 controller
旧真实FF paired数据采用base controller始终执行，或首步base、后续alternate Flow。4096对同state、eta、seed的首次动作完全相同；两种controller当前分支的全部函数查询也相同。未来执行规则却不同。
独立8/8 seed halves验证的controller delta energy为0.10512。在235个无数值异常的state–eta配对上，仅使用相同当前分支信息的模型，其不可消除Q平方误差的估计下界为0.02628，95% CI [0.01794,0.03545]。该下界条件于这两个controller和完整数值样本，不能外推到所有程序。
因此，Q(s,eta)仍可学习controller混合后的平均值，但无法同时预测两个controller各自的条件Q。完整执行程序的相关信息必须可区分。此结论不适用于已经包含未来行为的旧H20全部输入，不能用它替代第1项的诊断。

3. 旧数据库实际含有可学习关系：无新增Q rollout的验证
八个实际SQLite库及共享索引的审计中，重新找到真实FF的base/alternate-future Flow配对缓存。
去重复用42368条逐seed结果：80 TRAIN states/25344 outcomes，28 VAL/8832，16旧独立测试states/8192；6528份跨phase重复记录不重复计数。1728条旧Q16聚合记录逐一与raw outcomes核对一致。
再使用完整自然128-state Q4 screening pool的16384条旧结果进行扩大诊断；没有采用后来挑出的16-state高需求subset。两批诊断states均与TRAIN/VAL不重叠。
共58752条复用seed outcomes。更换critic编码没有要求重新生成这些标签。

主joint模型用Toy和Ring SOURCE数据共同训练；另外两个source-only模型各自只使用一个scene的TRAIN/VAL。两者是单source→held-scene诊断，不是原四场景三训一测LOSO。两种development scenes曾用于表示研究，故也不是完全domain-blind方法开发。

5. 数据生成机制本身与学习目标不匹配：已经证实什么
当前简单analytic controller bank全属于f(s,h)=lambda(target(s)-h)，其action-space Jacobian为-lambda I。六个参数中只有一个改变该响应算子，并且始终各向同性；参数数量不能等同于eta响应机制的多样性。
SOURCE Toy的768个完整state-controller Q1 panels中726个在全部16eta上标签相同。Q1不能证明真实Q完全一样，所以又对独立FINAL的8/8 halves做去噪interaction分解：Toy的eta相关成分合计约占0.528%；Ring约85.7%。Toy主要变化是state×controller，Ring强变化包括eta与controller×eta。两个scene需要学习的interaction结构非常不同。
两个scene按预先固定的strong reversal criterion都没有合格state-ranking reversal pair，不能把此batch当作“通过了switching测试”。新controller整体Q变化可学，与新state中改变eta的能力是两件事。
上述能量分解使用实际交付的operational verified-success。Toy没有numerical unknown；Ring的该分解不能无条件解释成无数值失败时的物理成功率分解，其physical-Q结论另由censoring bounds约束。
这证明当前数据对目标interaction的覆盖有缺口，支持停止在这一bank上盲目增加eta rollout。但它没有单独证明跨scene误差的全部因果来源。

6. 不是已经证明的唯一根因
完整field-query参数反演在既定analytic family的Ring20/20、Toy19/20探针中恢复六个参数；最终compact descriptor的24个局部Jacobian检验全部rank6。直接提供六参数的对照也没有稳定解决cross-scene失败。因此“只要再补controller参数就一定解决”不成立。
训练覆盖的同预算对照、训练/验证曲线、known-scene与held-scene强差距支持coverage和distribution shift问题，但没有隔离出唯一一种representation/optimization根因。
恢复已知环境常量没有一致修复。旧physical encoding确实省略了部分time/speed常量，但不能据此宣称四个固定benchmark存在已被证实的输入冲突。
在确认集之前冻结的operational-target对照也没有形成state-selection优势：matched-minus-mismatch为Ring 0.00pp、Toy -0.79pp（CI [-3.20,+0.49]）。因此数值未知样本的target定义也不能作为全部selection失败的单一解释。
目前不能严谨地说“cross-scene理论上不可能”，也不能说“数据集是唯一原因”。

7. 可以写进论文的结论
(a) 不同controller程序在相同physical state和eta下产生可重复的Q差异；单一当前动作/当前分支不足以唯一标识这些条件Q。
(b) 旧H20 feature cache存在controller归属缺陷，受控修正显著改善controller-induced Q差异预测。
(c) 静态controller函数描述配合physical state，在旧真实FF数据库的独立states上学到state×controller×eta关系；该证据条件于两种训练已见controller，且为development分析。
(d) 对未见analytic controller，在已见scene内可泛化Q值；跨scene的Q与state-conditioned eta selection尚未建立。
不能写“任意controller/场景零样本迁移已解决”，不能写“完整四场景FF LOSO已在本轮重跑通过”。DB和Four本轮未新跑，不用Toy/Ring结果代替。

仅列出、不继续执行的小修补：loss权重、ranking loss、temperature、weight decay、dropout、学习率、额外网络容量。若继续研究，必须首先补充能识别目标interaction的controller/geometry覆盖及完整输入契约；本轮没有开启该新实验，也没有用失败结果重调确认集。
