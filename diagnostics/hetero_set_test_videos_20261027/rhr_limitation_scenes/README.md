# 右手规则有局限的场景：右手规则 vs 流水线

文献对右手规则的批评：拥挤、杂乱环境里会引出新的死锁（Park 等，arXiv 2109.09041；Chen 等，arXiv 2210.04231），窄通道里会来回绕（活锁）或卡住（Chen、Guo、Li，IEEE TAC 2024，图 8；Chen 等 2210.04231，图 5）。
我们已跑过的 32 个冻结场景里，对应这两类的是 8 个拥挤方形场地和 4 个窄十字路口（路宽 ≤ 0.50 m）。

每对视频：同一场景、同一 controller、同一起始状态。
- `A_右手规则_卡住/相撞`：右手规则按文献的定义（卡住时往自己前进方向的右侧绕；40 步进展 < 0.05 m 触发，推力 0.35），之后同样经过安全投影；
- `B_流水线_成功`：流水线为该场景冻结的 η。

挑选规则：13 个 controller（去掉在该场景没过单机导航门的学习型实例）中，选"流水线减右手规则"提升最多的那个；取状态 8–23 中第一个"右手规则失败、流水线成功"的状态。24 局都重新跑过，结果与原记录一致。窄十字路口的 4 局右手规则是相撞：往右的推力把机器人顶进路口拐角。
