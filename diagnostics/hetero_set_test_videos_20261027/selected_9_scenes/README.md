# 九个场景的九对视频

每对视频是同一个场景、同一个 controller、同一个起始状态：
- `A_只加安全投影_卡住`：只加安全投影，不修正，超时卡住；
- `B_流水线_成功`：用流水线（generator 提 16 个 η、critic 选一个）为该场景冻结的 η，成功到达。

挑选规则：在 13 个 controller（7 个经典 + 6 个学习型，去掉在该场景没过单机导航门的实例）里，选"流水线减只加安全投影"提升最多的那个；再取状态 8–23 中第一个"只加安全投影失败、流水线成功"的状态。18 局都重新跑过，结果与原记录一致。
