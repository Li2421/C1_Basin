# Auxiliary Q-energy unknown-policy correction

The first auxiliary `controller_q_decomposition.py` implementation used `(outcome == success)` for crossfit energies, which implicitly assigned zero to numerical unknowns. This did not alter raw data, training labels, the necessity gate, primary selection comparisons, frozen models, or Stage C. It was inappropriate for interpreting Q interactions without missing-label uncertainty. The initial code and JSON are retained under `backups/decomposition_unknown_policy/`.

The corrected descriptive calculation keeps every unknown trial in [0,1]. Midpoint 0.5 is used only as an interval summary, never as a success/failure label. Let P be the balanced orthogonal centering projection for controller×η or state×controller×η, and a,b the two midpoint Q panels. If r_a,r_b bound their unknown-completion RMS deviations, Cauchy and contraction give |mean(Pa·Pb)−E_mid| ≤ r_a||Pb|| + r_b||Pa|| + r_a r_b. Every possible completion is therefore covered by the reported unknown-completion energy bounds. State bootstrap intervals expand each resampled estimate by these bounds. Level-SD bounds use the same RMS contraction. Without arbitrary-unknown assumptions, this is an auxiliary bounded sensitivity estimate rather than an unconditional unbiased estimate.

The revised `CONTROLLER_Q_DECOMPOSITION.json` reports controller×η energy 0.028448 with expanded 95% interval [0.023235,0.034666], and state×controller×η energy 0.022738 with interval [0.011014,0.034132]. Both remain positive on this fixed Ring/K16 panel; this describes interactions and does not establish a causal mechanism or a continuous basin shape.
