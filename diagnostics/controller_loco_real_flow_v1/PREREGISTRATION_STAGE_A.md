## Frozen design

Controllers in order: base_u_plus_w_v4_wide_macflow, base_u_macflow, base_u_plus_w_v3_macflow, base_u_plus_w_v4_train_targeted_macflow, base_u_v10_local_macflow, base_u_plus_w_v4_macflow, base_u_v9_local_macflow. Their full execution profiles, checkpoint SHA256, observation frames, JAX x64=false, FF, H700, K16, safety layer, evaluator, future root and seed key follow P1 unchanged. `flow_adapter.py`, P1 runtime and Round 3 feature/model code are imported, not edited.

Generate natural Ring development states with `state_generator.generate`: 128 train at seed 2026140000+i, 64 test at seed 2026150000+i. They are shared by all controllers. Before outcome acquisition, compare state UID/content hash with all DB states and named historical protocols, rejecting overlap. Train masks: random generator seed 2026101204, balanced 8 of 16 η per state, the same mask across controllers, each η represented 64 times. Each train cell has seeds 0–3. Every test state has K16, seeds 0–7. Source validation uses P1's 24 opened states and seeds 0–3. Never fit or choose checkpoints on test states. Test seeds 0–3 are reserved for the necessity gate and target fixed references; seeds 4–7 only for endpoint evaluation.

For each of seven leave-one-controller-out folds, source prior is equal-controller mean over train states for each η (using observed valid labels; unknown reported and bounded), maximized over K16. Target fixed η is chosen on seed 0–1 and evaluated on 2–3, then vice versa; their average minus source-prior performance on 0–3 is L. State-cluster bootstrap with seed 2026101205 and 2000 resamples gives 95% CI; unknown success is bounded by 0/1 with shared unknown outcomes cancelled in paired contrasts. Necessary fold iff L>=0.05 and conservative CI lower>0. State-oracle crossfit is descriptive. Fewer than two necessary folds makes primary transfer inconclusive.

Five 16-head MLP arms use physical23 plus R0, R3 compact64, R4_action (projected η0 executed action plus projected η Jacobian at t0 and fixed 0.1 goal-direction probe), R4_openloop, or R3+R4_action. R3 dimensions 256 as stored by Round 3 `compact_field`, R4_action/openloop 64. All static queries forbid `env.step`. Same source data, balanced controller sampling, AdamW 0.0008/weight decay 0.0001, clip norm 5, two SiLU width-64 layers, 12,000 optimizer steps and Round 3 checkpoint schedule. Only labelled heads contribute loss. Three fit seeds 17,23,41. Source-only normalization; source P1 validation NLL chooses checkpoint. Models run on Slurm GPU shards.

On each held controller, compare selected η success on test seeds 4–7 to (a) source pooled fixed η, (b) nearest source controller's train fixed η in source-standardized mean R4_action space, (c) R0 critic, and (d) target fixed η selected on test seeds 0–3 (descriptive target-label reference). Also report calibration with target train labels from k=1,2,4 states: fixed prior and critic logit offset, explicitly target-supervised. Wrong-controller descriptors are all six source descriptors on the identical held states, averaged over them. Pool only necessary folds. Use paired state-cluster bootstrap, >=2000 draws, seed 2026101206; max-T simultaneous two-sided 95% correction over four non-R0 arms × three main controls and four matched-vs-mismatched comparisons. A representation transfers only if each of its three success differences and matched-minus-mismatched has positive simultaneous lower CI. Report per-fold success, Q MSE, controller×η pattern correlation and unknown bounds separately. Q metrics cannot establish selection transfer.

If <2 necessary folds, neither branch runs. Stage B/C status must be reported even when not executed.
