# Exploratory separation of controller prior and state-dependent selection

This analysis was specified after Stage A/B outcomes were opened, but before reading any Stage C outcome. It is auxiliary and does not change Stage C arms, checkpoint rules, η candidates, primary contrasts, decision gate or rollout budget.

For each frozen Stage A/B critic and fit seed, query its Q prediction on the 128 original S_train initial states with the held controller's already computed static descriptors. Do not load any target labels. Choose one controller-level η by argmax of the mean predicted sigmoid(logit) across those 128 states. Save predictions, chosen η and checkpoint hashes before reading Stage C outcomes. This is zero-target-label regime estimation from an outcome-blind initial-state sample; it is not few-shot target calibration.

Compare the actual state-specific selector against this frozen controller-level η on Stage A/B test seeds4–7 and, for Stage B passing arms, Stage C test seeds4–7. Report selection histograms and fraction choosing each η. Use the same physical-state paired conservative unknown policy (identical η cancels), average over fit seeds, then average necessary folds. Use 5,000 paired state bootstrap draws, max-T over the four Stage A/B representation contrasts within each panel; Stage C uses two frozen arms. Mark all these prior-decomposition results EXPLORATORY. A main zero-shot transfer pass does not by itself establish state-specific advantage over this learned controller prior. This procedure uses no target success labels or future rollout information to construct the predictor or its fixed η.
