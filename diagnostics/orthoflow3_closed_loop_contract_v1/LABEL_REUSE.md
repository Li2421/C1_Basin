The executed eta is held fixed for the entire continuation both in dataset
labeling and evaluation. No reselection experiment is warranted. The first
Flow suffix is an independent reference probe in Four/Ring, but a committed
first action in Double. This distinction is in the physical controller
protocol, not a discovered action-resampling bug.

The waiting witness establishes a time alias exactly. Active Four rotation
can change actual Flow suffix, so it is **not** an exact-input alias witness.
Existing orientation-dependent outcomes limit the claim of invariant
continuation, but do not by themselves prove a second exact representation
bug. Preserve policy-frame information conservatively in future encodings.

All v2 labels remain valid for their original snapshots. The repaired input
adds time without changing labels. Phase-B weights are dimension-incompatible
with the repair and are retained only as the pre-repair comparator. Phase-B
proposals, physical rollouts and historical scores remain valid records of
that original controller. No outcomes are relabeled to enforce symmetry.
