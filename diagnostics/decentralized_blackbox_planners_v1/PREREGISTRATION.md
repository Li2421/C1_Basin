# 一、背景与问题

**论文定位（用户 2026-10-16 确定）：** 修正黑盒 controller 在安全层下产生的死锁。
- **黑盒：** 方法不依赖 controller 已知的控制律公式，只允许探测它的行为。学习得到的模型、模型预测控制、A* 一类规划器都算黑盒。
- **白盒（不在主线范围内）：** 直奔目标、势场这类手写的闭式规则。
- 任何原因导致的死锁都在范围内；安全层是设定，不是假定的成因。

**分布式这条线的已有结论：**
- **round30 至 round30c：** 14 个不通信的分布式一步学生，是从联合 MACFlow 蒸馏得到的黑盒学习型 controller。

  - 加上集中式确定的"前 500 步 η13、之后 η10 的时间表"：94.2%；
  - 公平调参的右手规则：11.3%。
- **round30d：** 只靠修正、不用学习型 controller 时只有 28.1%，说明修正与学习型 controller 是协同的。

**本轮问题：** 结论是否只对蒸馏学生成立？换成其他黑盒 controller 族，在同样的分布式安全层下：
1. 会不会产生死锁或停滞；
