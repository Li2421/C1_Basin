# Four formulation basin figures

现有四 formulation factorial 缓存包含两个物理场景：Toy GiveWay 和 Ring Exchange。每个场景一张 2×2 3D 图；所有 projection 均使用相同 16 个 η 点。旧 pairwise comparison 图已移入 `_internal_archive/previous_pairwise_comparisons/`。

## Tables and notes

- `four_formulation_state_candidates.csv` — each scene 的 top 5 candidate states。
- `selected_state_toy_give_way.csv`、`selected_state_ring_exchange.csv` — selected state 的 η coordinates 与 TT/TF/FT/FF B15 membership。
- `four_formulation_selected_summary.csv` — selected states、robust counts，以及所有 figure filenames。
- `four_formulation_basin_notes.txt` — data scope、selection score、B15、hull notes。
