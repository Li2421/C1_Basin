# Three questions only — archived-label test

Historical audit: P1 has 14 real Ring FF controllers, 24 shared physical states, K16, Q4, 272 numerical-unknown seeds. Round 2 has matching R5 static response features; Round 3 has same-state leave-controller-out matching predictions. P1 raw records save first action, terminal summaries and episode length, not full trajectories. Terminal outcomes/episode lengths will not be used as behavioral inputs. No compatible full closed-loop trace panel was found in these artifacts. Static behavior→Q predictive association is testable; a complete closed-loop mechanistic explanation remains untested.

Reuse all labels/features. New rollouts: 0. Add only R0 versus R5 lightweight kernel critics, because the existing matching reader did not test new physical states. This is an exploratory reanalysis of opened data, not a new independent confirmation.

Outer: leave one of 14 real controllers out, crossed with four deterministic state groups (P1 state index modulo 4). Train on the other 13 controllers and 18 states; predict the held controller's 6 states. Across 56 folds every held controller/state gets one source-only prediction. Inner: three deterministic controller groups within the 13 sources crossed with three groups of the 18 outer-training states; each inner fold holds a controller group and a state group. Both labels and features used for normalization/fitting come only from its training controllers/states. The held outer controller/state labels never choose settings.

Models: same 16-head kernel ridge critic. A physical state is positions, velocities, goals (24 coordinates); η selects the corresponding frozen K16 head. R5 additionally receives existing outcome-free, current-state controller descriptors. R0 kernel is RBF(state); R5 is RBF(state, descriptor), which supports controller×state×η interactions. Physical coordinates use source coordinate standardization; R5 uses source semantic-block RMS scaling (same archived six blocks, no added representation). Bandwidth {0.5,1,2}; ridge penalty {0.0001,0.001,0.01}, matrix regularization n×penalty. Center each η head on its source mean; clip final predictions to [0,1]. Inner objective: average held Q-midpoint MSE, deterministic grid order tie break. Unknown source labels use midpoint only as a modeling convention; all test metrics retain intervals.

Question 1: compare R5 and R0 Q error, η-centered error and intervention advantage error relative to source fixed η; additionally replace R5's held descriptor with every source controller's descriptor at the same held physical state, without changing the trained model. Report mean donor error (not error of averaged donor predictions). This tests task relevance of static controller response, not causal mediation or full closed-loop behavior sufficiency.

Question 2: report per-controller and overall held Q MSE, unknown intervals, within-state candidate rank, and probability calibration. Distinguish new-controller/shared-state earlier evidence from this new-controller/new-state test. No best-arm selection from held results.

Question 3: argmax frozen predictions over common K16, compared with R0 and source-global-fixed η (selected solely from each outer training fold). Report selected Q, coupled numerical-unknown gain intervals, empirical oracle regret, controller-wise signs and paired descriptive checkpoint bootstrap. Q4 oracle is noisy empirical reference. Claim stable improvement only if gain lower endpoints vs both baselines have positive mean and positive descriptive 95% bootstrap lower endpoints and at least 10/14 controller means are nonnegative against both. No population confidence claim for this opened, selected checkpoint inventory. No additional feature/model search or rollout from a negative result.
