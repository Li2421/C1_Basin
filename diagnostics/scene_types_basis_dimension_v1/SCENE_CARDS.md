# 场景卡与文献对应

尺寸是本轮 prompt 的新建米制场景与冻结标定结果，不是原论文地图复现。下列文献支持场景类型的动机，不证明这些具体尺寸的联合可解性；后者见 `FIVE_LAYER_FINAL.json`。圆周、交通、房门、拐角与集结类别核对了 [Francis 等的场景分类与示例](https://arxiv.org/html/2306.16740v4#S7)。把人群交互类别移植到同质机器人是本轮设计选择；没有测量人类舒适度、手势或社交规范。

| 场景（外观与关键参数） | 空间与交通 | 对应动机及适用边界 |
|---|---|---|
| 开阔·圆周对穿，10台、起点圆半径1.25m、机器人半径0.05m | 开阔、对心汇聚 | Francis 周向交叉；[Wang 2017](https://liwanggt.github.io/files/A2_Safe_Swarm.pdf) 的多机冲突背景。本轮是新状态与冻结MPC，不继承文献死锁分类定理。 |
| 开阔·两股垂直纵队交叉，要求3×3m、每队4–6台 | 开阔、垂直交通 | Francis 的垂直流类型。旧横队原型不符合纵队要求，已失效；尺寸／半径选择未获确认，本轮不计入正式结果。 |
| 宽走廊·同向换道，长4m、宽0.9m、6台、半径0.10m | 走廊、同向换道 | Francis 的同向交通与超越类型；本轮没有规定不同巡航速度，主要是终端车道互换。 |
| 封闭方形场地·随机起终点，2.4×2.4m、10台、半径0.13m | 四面墙、随机交叉 | Francis 的拥挤导航类型；沿用原方形构建，无人类行为模型。 |
| 方岛环岛·四向，3.2×3.2m、中心岛0.5m、入口宽0.6m、8台 | 中央障碍、四向竞争 | Francis 的交叉类型加本轮方岛拓扑变体；不是 Merry-Go-Round 的原生测试地图。 |
| 带障碍的圆圈对穿，8台、起点半径1.40m、机器人半径0.05m | 固定障碍、对心汇聚 | 沿用已有八机静态障碍构建；周向交通类别移植，真实墙段和原名字路由保留。 |
| 散布障碍森林·随机起终点，要求3×3m、12个0.3m方块、净距0.5m | 散布障碍、随机交通 | [BARN](https://www.cs.utexas.edu/~xiao/BARN/BARN.html) 提供拥挤几何导航的动机。本轮要求存在面积排斥矛盾，未实例化，也没有运行BARN官方地图。 |
| 窄门·两组对向互换，门宽0.30m、两侧各3台、半径0.10m | 两房间、单门双向 | Francis 的窄门与进出房间类型；本仓库 Gap 双向共享资源母版。 |
| 单向挤门·疏散，门宽0.30m、6台、半径0.10m | 两房间、单向汇入 | [Helbing等2000](https://www.nature.com/articles/35035023) 的拥挤疏散动机；这里只移植瓶颈流型，不使用恐慌、接触力或原人群动力学。 |
| 单车道长走廊·两组对向，通道长1.6m、宽0.30m、两侧各3台 | 单车道、对向 | Francis 的正面会遇与窄走廊类别；必须区分控制失败与几何上能否退回房间。 |
| 单车道走廊＋中间让行湾，通道长2.4m、宽0.30m、侧湾0.50×0.30m、两侧各1台 | 侧袋走廊、对向 | 本仓库早期让行湾的拓扑推广；这是工程机制变体，没有冒称某论文的逐图复现。 |
| L形盲角·对向，通道宽0.50m、两臂1.6m、4台 | 拐角、对向 | Francis 的盲角类别；本轮完全可观测，未引入遮挡感知或未知行人。 |
| T形路口·三向，路宽0.60m、每臂2台、半径0.10m | 三臂路口、混合转向 | Francis 的路口类别；按冻结状态随机分配转向，不用控制结果选择目标。 |
| 窄十字路口·四向对穿，路宽0.40m、4台、半径0.05m | 四臂路口、对心 | Francis 的路口类别；沿用原十字构建并保持原机器人半径。 |
| 四房间连通·串联瓶颈，3.2×3.2m、4个0.40m门、10台 | 多房间、多次瓶颈 | [公开MAPF地图类别](https://www.movingai.com/benchmarks/mapf/index.html)中的房间结构及本仓库双瓶颈推广；本轮连续空间地图是自建，不继承离散图规划保证。 |
| 货架仓库·窄巷，3.6×2.4m、3×2排0.8×0.3m货架、巷宽0.40m、10台 | 货架网格、随机取送 | [公开MAPF地图类别](https://www.movingai.com/benchmarks/mapf/index.html)中的仓库结构；不使用其官方地图或任务标签。 |
| 集结到小区域，3×3m、10台、中心2×5目标格、间距0.50m | 开阔、集中到达 | Francis 的加入群体类别；本轮只保留几何集结，不宣称完成社交加入群体任务。 |

完整12个状态、每状态路径、真实墙段与选档配置保存在 `SCENES_FROZEN.json`。每类一个固定地图，四个搜索初态、四个留出初态，另四个保留不用。所谓“类型覆盖”只针对这些冻结实例，不代表对同类所有几何的泛化。
