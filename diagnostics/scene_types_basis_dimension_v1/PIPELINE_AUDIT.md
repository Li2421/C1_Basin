# 真实流水线审计与本轮冻结边界

来源为 `BACKEND_BUILD.json` 指定的生产快照，62项逐文件哈希核验；共享修正字典原文件只读。此文描述实际执行，不以早期讨论公式替代代码。

集中式随机采样模型预测控制参数为 `[10,64,20]`，梯度下降模型预测控制为 `[10,20,0.05]`，读取 `cross_scene_correction_v1/SELECTED_CONTROLLERS.json` 的 `xsc_swap_n6` 项。二者不是神经网络 checkpoint，本轮没有训练、替换或加载另一个学习策略。原名义输出限速、真实目标到达掩码后，第一次逐机器人安全投影；添加修正；第二次同样安全投影；原环境步进。没有新增硬等待约束。

原三列的实际实现为：

- 朝目标：`bounded_rows(goal-position, max_speed)`，并非“期望速度减当前安全动作”。
- 横向放大：`3.303687238760696 * (safe - Q_goal safe)`，其中 `Q_goal=GGᵀ/(GᵀG+epsilon²)`、`epsilon=1e-6*max_speed`。这是冻结全局尺度，不逐状态再归一化；安全动作为零时该列为零。原始控制输出横向残差列则使用投影前 nominal，且依字典的自身限幅规则，不偷改为同尺度别名。
- 互斥分离：先对每一个 `p_i-p_j` 向量逐行径向限幅再求全体均值；然后按原接触门控置零。不是先求原始均值再限幅；目标附近全部完成的机器人对不触发门控。邻居传入无限半径，所以平均项本身为全对，门控半径为 `1.25*(2r+agent_margin+1e-4)`。

这里统计的是附加修正的列数；删除朝目标修正列并不删除 nominal 的任务目标、路线引导或安全参考动作。因此一列切向修正仍由原名义控制器承担基础目标推进，不能称为只有一维动作空间的完整控制器。所有列系数为零时仍执行两次原安全投影的 nominal。

逐机器人安全层只纳入距离≤0.5m的机器人对／墙体。机器人约束为 `2(p_i-p_j)·u_i >= -0.5*(||p_i-p_j||²-d_safe²)`；墙约束为最近墙段的单位法向速度下界。`gamma=gamma_wall=1`，安全 buffer 为 `1e-4`，速度球半径0.5m/s，时间步0.05s。原主投影容差见只读 `HardProjectionConfig`：`solver_ftol=1e-12`、`feasibility_tol=1e-9`、`optimality_tol=2e-6`、`max_iterations=200`。原 Clarabel、同问题更紧求解与非线性 polish 均保留。

原 `SwapSafety.restore` 本来就含速度松弛、再到安全 minimax 恢复。保留它们并不意味着每一步都满足未恢复的原约束。结果分别记录 `restoration_steps`、`constraint_violation_steps`、`sampled_speed_violation_steps`；五层证据只用后二者均为零的 C1 成功作为原约束下的构造性见证。没有为修正族新开恢复分支。

原运行时已有可选的 `theta` 阶段切换与 `eta_a/eta_b` 接口。本轮候选固定系数，`theta=None`，`switch_step=None`，不据此判断时序方法无益。新增列依状态变化，角色与激活规则仍是原字典版本；“固定系数”不等于每步动作不变。

有遮挡的地图依本轮说明使用原 `Geometry.path` 路线引导；改变的是本轮私有输入适配层，目标到达与物理成功仍用真实目标。开阔图50对逐位等价、两组非零三列参数16对原流水线回归已通过。新增墙体半径同时在几何与安全配置设为4/600；旧轮不回写修复。

成功要求原环境判成功且无碰撞；连续步间 swept 碰撞仍计失败。用尽原任务时限记 timeout，不叫死锁。接口、路线或求解异常保留 unknown，数值未知不自动重跑。全队列截断时间对所有未完成局赋完整冻结时限；这是失败惩罚统计，不是它们实际运行到异常的物理时间。

每个请求包含完整初态、真实目标、几何、控制器源码与配置、精确参数和seed。两名义控制器在相同物理状态下匹配随机流；候选身份包含加速认证版本。官方 preflight 后仅补缺失，worker写journal，协调进程单独merge并读回核验。旧轮标签仅在执行语义完全相同时精确复用；本轮新地图没有冒用旧轨迹标签。

论文端口保留各自原生控制与安全核心，并承载到共同 SI 物理环境；它们没有接收 C1 外部路线引导，也不是“只换修正基”的消融。双积分器／单轮车的原理论保证不能直接搬到此适配。已封存端口的完整限制见上一轮报告，本轮 additionally 记录 IMPC 栅格边界适配revision2，不修改作者仓库。
