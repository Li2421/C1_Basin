# 朝目标列的参数域与最小支持统计

原参考三列族保留朝目标系数区间 `[0.5,1.25]`。删除朝目标列的家族把该系数固定为0。二者不是嵌套的参数域；含朝目标列的大字典不能靠“把这一列系数设为0”直接复现不含该列的成功记录。

因此，本轮子集闭包只沿其他17列的零系数传播，朝目标存在/不存在分开统计。候选池也执行同一合法性过滤。若两个参数域的成功见证并集没有任何单一合法家族能在已测试记录中覆盖，则报告“有限候选池内无单一全覆盖族”，保留已观测的最大合法覆盖，不把零系数偷偷放进原正下界盒里。

只加安全投影的已知成功可作为不含朝目标列家族的全零修正见证，但不能算作原正下界三列族的候选。S4 的横向放大+互斥分离家族，是原三列朝目标系数为0的边界消融。独立验证另冻结最多6个该边界候选，并与原16个正下界三列候选分开报告；它不是对整个 `[0,1.25]` 连续参数域的最优解。

这种处理落实原研究要求：“Goal 下界放宽时 B3 也要作同样参数范围消融”。小维家族的优势可能来自取消强制正的目标放大，不能全部解释成新增空间方向更强。结构维度、参数盒、激活时机与全局固定参数的差异必须分开讨论。
