1. 共同输入和名义参考
物理步 t 中固定 x=(p,v,g,场景配置及事件历史)，key 由 H/runner.py:20-27 对
future_root、初态 UID 的 SHA256 token、seed、t 逐次 fold_in 构成；同一初态/seed/t
的 TT 与 FF key 相同。观测由 F/source/single_integrator/environment.py:128、
F/source/ring_exchange/local_frame.py:40 构造；Ring 在逐机器人径向/切向局部
坐标中使用 23 维观测，Toy 用 10 维观测。checkpoint 的归一化参数与网络固定。

令 ξ=jax.random.normal(key)，z0=ξ，sk=k/10。原生 sampler 连续执行十个 Euler 步
z(k+1)=zk+0.1*vθ(观测标准化,zk,sk)，k=0,...,9；然后先动作反标准化、逐分量
clip 到 [-1,1]、逐机器人径向速度球限制、Ring 的局部到世界坐标旋转、float64
世界坐标径向重限制，得到 a_ref。来源 F/source/new_benchmark_common/macflow.py:96-116、
F/poc/field_controller.py:139-158,198-213、F/validation_v2/adapters.py:90-137。

共同准备顺序为 a_safe=Π_x^T(a_ref)，B=B(x,ξ)，δ=Bη，见
F/poc/field_controller.py:215-220。B 的三个列向量逐机器人为：
  G_i=bound_v(g_i-p_i)，
  L_i=3.303687238760696 [a_safe,i-
      ((a_safe,i·G_i)/(||G_i||²+(10^-6 vmax)²))G_i]，
  R_i=(N-1)^-1 Σ_(j≠i) bound_v(p_i-p_j)，
  bound_v(q)=q min(1,vmax/max(||q||,10^-30))。
来源 F/source/shared_control/basis_families.py:114-152 与
F/source/shared_control/diagnostic_corrector.py:10-40。B 依赖位置、目标、观测中
的上一速度、名义 Flow/key、首次安全投影及固定几何，不是 B(p)；一次动作中不依赖
η。η 在 episode 固定，但每个物理步重新计算 B（F/validation_stage2/run_rollouts.py:23-35）。

2. 投影目标和安全集
U_x={u:A(p;墙体/半径/CBF参数)vec(u)>=b(p;墙体/半径/CBF参数),
         ||u_i||_2<=vmax 所有 i}。
每对机器人使用 h_ij=||p_i-p_j||²-(2r_agent+agent_margin+buffer)²、
行 ±2(p_i-p_j)、下界 -gamma*h_ij。每条有限墙段取 clip 到段的最近点 c，
使用 h_iw=||p_i-c||-r_agent-r_wall-wall_margin-buffer，法向 (p_i-c)/||p_i-c||，
下界 -gamma_wall*h_iw。F/source/shared_control/hard_projection.py:72-151；
Toy 对应 F/source/single_integrator/cbf.py:51-93。Ring 投影墙体为 48 边外接
中心障碍与 48 边内接外边界，物理评价仍使用真圆
（F/source/ring_exchange/safety.py:19-60）。

Π^T 是 F/poc/field_controller.py:69-80 的标准欧氏投影；Toy 通过
F/validation_v2/adapters.py:35-39 的 SLSQP/切平面主求解器和重试。
Π^F 是 F/poc/field_controller.py:82-93 或 Toy adapter:40-47：先单独投影
速度球；若全部 CBF 行也满足，则直接返回该精确交集投影，否则调用 Π^T。
求解失败会抛错，不以伪动作替代。feasible set 只由当步位置和固定几何参数
直接决定，不由 v、g、ξ 或 η 直接决定。

3. TT/FF 实际分支
记 Ring 的局部到世界坐标变换为 R_x，Toy 为 I；Σ,μ 来自 checkpoint。
场积分的 h 是世界坐标动作样本，不是机器人物理状态：
  h0=R_x(μ+Σξ)，
  f_x(h,sk)=R_xΣvθ(观测标准化,Σ^-1(R_x^-1 h-μ),sk)。
h0 没有经过原生 sampler 的 clip/速度限制；安全参考 a_safe 不作为 h0。
对每个 k=0,...,9，r_k=1-k/10，α_k=min(1,0.1/r_k)：
  q_k=h_k+r_k(f_x(h_k,s_k)+δ)，
  c_k=Π_x^F(q_k)，
  h_(k+1)=(1-α_k)h_k+α_k c_k。
FF 对完整 proposed endpoint q_k 投影十次，输出 h10；末端仅 assert_safe，
没有额外 clip/投影。TT 输出 Π_x^T(a_safe+δ)。场积分每一步的 h 和投影结果
反馈下一步网络评估，物理 p,v 在伪时间十步中冻结。来源
F/poc/field_controller.py:96-107,222-256；四链分派
F/validation_stage2/factorial_controller.py:23-40。

4. 局部对象
源码允许把任意联合物理动作 δ 输入 TT 末端 target 或 FF integrate，故固定
(x,ξ,a_ref,a_safe,B) 与正规光滑分支时，ambient M_p=D_δu_p(δ)|δ=0 可直接
辨识，G_p=D_ηu_p(η)|η=0=M_pB。TT 在 a_safe 投影边界经常不满足双侧光滑性；
不能无条件写 M_TT=DΠ。FF 的 M 随投影活跃集及完整 Flow 路径变化，不是全候选
幅度有效的常矩阵。旧缓存的 ambient 有限差分形状和原始数组见
H/transfer_mechanism_v2/state_dependence_control/*.npz，本次重新读取、独立方向
验证与训练/留出 Q 检验见 jacobian_probe.py。

5. 物理继续执行与诊断裕度
Toy/Ring env.step 将合法世界速度原样执行：p'=p+0.05u，v'=u；任何非有限或
超速动作报错。Toy 的真实扫掠墙/机器人碰撞、目标、窗口死锁/超时在
F/source/single_integrator/environment.py:170-229；Ring 的真圆与扫掠机器人
碰撞、目标/超时在 F/source/ring_exchange/environment.py:281-334。
当前评估仅有二值 success，没有生产用连续 ρ。
本审计为固定 seed 构造诊断量
  ρ=min{ max_(1<=t<=T) min_i(goal_tol-||g_i-p_i,t||),
          min_(1<=t<=T) min_j(swept_clearance_j,t-collision_threshold_j) }。
Toy 的 outside_workspace 为真时把第二项限制为负数。ρ 用真实 env.step info 的
连续扫掠距离，不从渲染帧重构。有效已终止轨迹中，除精确等号点外，ρ>0 与
当前 evaluator 的碰撞安全成功符号一致；数值异常时未定义。该 ρ 是诊断
surrogate，不是仓库原有函数。具体实现 closed_loop_probe.py:36-75。
