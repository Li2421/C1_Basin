# 跨 controller type 的实现：跨学习型类型第一轮

完整性审计通过：8,165 个开工受保护 Python 文件、导入来源及两个仓库记录的比对见 `INTEGRITY_FINAL_COMPARISON.json`。开发目标未通过：零样本选择器类型等权成功率 95.68%，相对按比例切换时间表增加 1.30 个百分点，95% CI [-0.23, 3.00]；优越性未通过。规模曲线的点估计单调不增，七源类型相对单源类型的成功率增益为 15.83 个百分点，CI [8.95, 23.50]；不能据此宣称完整的类型多样性优势已成立。锁定终点一在现有强化学习类型上未通过；终点二为 INCOMPLETE_LOCKED_COHORT，未通过完整主终点；终点三在现有类型上的数值目标通过，两类型完整判定仍缺失。参数共享独立近端策略优化强化学习策略（ring_ippo）六实例完成一次性确认；隐式能量行为克隆策略（implicit）未通过原两峰合成门，未训练 Ring 策略，保留缺口。

本轮完成了可复查的动物园、开发比较、冻结选择器、规模曲线和现有锁定类型的一次性确认，但没有做出已获证据支持的跨类型自适应选臂。所有失败迭代与缺口均保留；开发结果为 DEVELOPMENT，锁定结果为 CONFIRMATORY，后者的完整两类型主终点不能由现有子集替代。

**动物园、训练和证据门。** 八个开发类型、56 个合格实例：环形交换场景流匹配策略（Flow）14 个；高斯行为克隆策略（gaussian）、确定性行为克隆策略（deterministic）、混合密度行为克隆策略（mixture）、扩散行为克隆策略（diffusion）、动作分块行为克隆策略（chunking）、循环网络行为克隆策略（recurrent）、条件变分自编码器行为克隆策略（cvae）各六个。历史38实例直接复用，新增18个开发实例训练并通过能力门。强化学习六实例各完成2,000万机器人步，无训练安全层，按32个训练留出state的只执行动作成功率选checkpoint；评估用原环境。清单和每实例checkpoint哈希见 `ZOO_MANIFEST.csv`，配置、曲线、原始训练记录见 `TRAINING_CONFIGS.json`、`IPPO_TRAINING_CONFIGS.json`、`policies/`、`figures/chunking_dev_loss.svg`、`figures/recurrent_dev_loss.svg`、`figures/cvae_dev_loss.svg`、`figures/ring_ippo_mean_reward.svg`及对应原始曲线JSON。

32/32条历史复现的首动作、终止、步数和完整位置轨迹逐位一致。六套坐标系和策略状态/随机键测试通过。训练环境float64位置最大误差3.11e-15、扫掠间距误差4.44e-15，两种精度各256条终止类型和步数均一致。原float32附加观测测试混入累计轨迹漂移，原失败保留，改用同一历史状态作观测检查而不放宽阈值，见 `TEST_HARNESS_AMENDMENT_20261018.json`。原冻结critic的66个历史选臂在CPU上全部一致，附加概率阈值的CPU失败保留；GPU重核通过原2e-6阈值，当前56实例三种比较方法的GPU选臂也与提前封存的CPU选择一致。

**开发结果。** 岭回归预测各臂相对按比例切换时间表（S500）的成功率差；特征填补、标准化和内层超参数选择均只拟合源类型。全部八折及内层误差在 `iterations/ridge_v1/OUTER_FOLDS.json`，闭式回归没有按训练步数挑checkpoint；历史模型早期过拟合问题通过源类型内嵌套调参检查。九次结构/特征比较逐次保存在 `ITERATION_LOG.md`，最终选择规则先于结果封存，精确并列取最早版本。

所选模型交叉拟合事后最佳平均遗憾为 -1.05 个百分点，最大controller遗憾 6.25 个百分点，伤害数 0；没有留出类型比按比例时间表差超过3个百分点。Controller等权成功率 95.34%，相对按比例时间表增益 1.26 个百分点，CI [0.06, 2.54]。负交叉拟合遗憾来自小样本选臂噪声：交叉拟合的事后选择可能低于强固定臂，不表示超越真实oracle。

54个探测可用实例全部选择按进度切换时间表（Sprog），两个保留历史探测数值失败的实例回退按比例时间表。每折仅用源类型选择最佳固定臂也全部选按进度时间表；选择器相对该基线的增益为 -0.042 个百分点，CI [-0.29, 0.06]。统一按进度时间表成功率 95.72%，样本内每controller最佳 96.11%，样本内自适应空间仅 0.391 个百分点。这是当前样本的描述性差距，不是总体不可提升的证明。不能把更好的统一修法当作行为特征已支持实例级选择。

固定七实例的受限对照中，七源类型相对单一流匹配源类型提高 4.44 个百分点，CI [1.46, 8.83]；该对照支持在此条件下增加源类型的收益，但其点估计并非逐档单调，且不能据此证明实例级自适应选臂。

主设计在三个及以上源类型时至少有18个源实例，单类型最多14个，完整等实例数对照客观不可构造。保留所有可行的精确数量匹配，并额外报告固定七个不同实例的对照；该补充仅限七个非流匹配留出类型，单类型供体只能是流匹配。它不能外推为覆盖全部类型的公平多样性结论。

**冻结及一次性锁定确认。** 模型、24维特征定义、缺失回退、同结构行为指纹对照、选择和终点分析代码在 `FROZEN_PIPELINE.json` 与收据封存。锁定选臂UTC为 2026-10-18T05:43:30.308580+00:00，第一批评估/调参标签提交UTC为 2026-10-18T05:43:37.844128+00:00。探测关闭终止并不读取成败；选臂收据早于第一批标签，冻结后没有据锁定结果重训、改特征或改阈值。

现有强化学习类型：只加安全投影成功率 92.19%，按比例时间表 98.96%，冻结选择器 99.48%。按比例时间表减安全基线为 6.77 个百分点，CI [0.00, 16.67]；选择器减按比例时间表为 0.52 个百分点，CI [-2.08, 3.12]；交叉拟合遗憾 -0.52 个百分点、伤害数 0。多数实例安全基线≥98%的例外规则未触发，完整主终点仍受隐式能量类型缺失限制。

现有强化学习类型的样本内最佳固定修法为 按进度切换时间表。无成败安全探测的严格冻结比例均值为 0.0000，在动但不前进比例均值为 0.0087。这些是描述性停滞诊断，timeout不直接称为deadlock。超出开发特征范围的每实例比例见 `CONFIRMATORY_RESULTS.json`；逐条只执行动作→安全投影转移见 `LOCKED_NOMINAL_TO_SAFETY_TRANSITIONS.csv`，汇总见对应SUMMARY。

实际安全基线的 30 条超时轨迹另作描述性复核：最后100步中，未到达机器人步的严格冻结比例为 0.067%，在动但不前进比例为 61.73%。这些超时尾段主要表现为在动但不前进；没有独立的死锁验证。完整逐条轨迹索引与分母在 `LOCKED_TIMEOUT_TRAJECTORY_DIAGNOSTICS.json`；这是确认后描述补充，没有新增假设检验、rollout或改变冻结终点。六个强化学习实例有 33.3%–50.0% 的机制特征超出开发实例的逐维范围。

代表性轨迹按锁定前写定的中位controller、中位episode时长规则选择；同一state/seed的只执行动作、安全基线和选择器轨迹分别见 `figures/ring_ippo_nominal_only_trajectory.svg`、`figures/ring_ippo_safety_baseline_trajectory.svg`、`figures/ring_ippo_pipeline_trajectory.svg`。图仅读取哈希核验后的轨迹，不修改仿真。隐式能量类型没有有效Ring checkpoint，不能提供或伪造其轨迹。
