# 跨学习型类型结果表

开发模型迭代：`ridge_v1`。成功率为下界百分数，方括号为5000次配对成簇bootstrap的95%区间；unknown另报上界。
类型等权先重抽类型，再重抽controller和state；seed重复保持成簇。Oracle在每次bootstrap中重选。
锁定类型缺失时，锁定合并仅描述现有实例；不能把该行当作两类型完整主终点。

方法全称（代码只作列身份）：

- 只执行 controller 动作（`nominal_only`）
- 只加安全投影（`all_safety_baseline`）
- 全程 η10（`all_F10`）
- 全程 η13（`all_F13`）
- 前100步 η13后 η10（`all_S100`）
- 前300步 η13后 η10（`all_S300`）
- 按比例切换时间表（`all_S500`）
- 按进度切换时间表（`all_Sprog`）
- 持续右手规则（`all_RHR`）
- 本轮零样本选择器（`pipeline`）
- 原冻结扩展选择模型（`frozen_round38`）
- 行为指纹同结构选择器（`r5_pca2_pipeline`）
- 原不看 controller 的 critic（`A0`）
- 原 controller 级 critic（`A3`）
- 探测规则选择（`G_E`）
- 前2个调参状态选臂（`few_labels_2`）
- 前4个调参状态选臂（`few_labels_4`）
- 前8个调参状态选臂（`few_labels_8`）
- 交叉拟合事后最佳（`crossfit_oracle`）
- 样本内事后最佳（`in_sample_oracle`）
- 每类型最佳固定臂（`type_best_fixed_oracle`）
