# Controller intervention generalization ledger

- Frozen baseline: original four-scene LOSO candidate pools and partial-count labels. Generator unchanged; no artificial mode IDs.
- Pilot: 72 matched source state–eta pairs, base Q16 reused, 1,152 alternate Flow continuations executed and merged. B15 flips DB/Four/Ring = 3/22/14. One Ring numerical unresolved seed retained.
- Pilot context: physically summarized eight-step Flow+safety and eta-conditioned response, two independent fixed probe streams. Linear source-family held-out controller-contrast probe did not beat pooled prediction overall; this is not LOSO evidence.
- Balanced source expansion: 48 source states (12 train + 4 validation per DB/Four/Ring), two robust and two confirmed non-B15 eta per state. Base partial observed counts retained; alternate controller Q16 requested 3,072, of which 80 exact reused and 2,992 executed. Results merged; four numerical seeds unresolved. Confirmed non-B15-to-B15 flips DB/Four/Ring = 1/1/6, B15-to-non-B15 = 1/28/13. Exact B15 eta-ranking reversals under controller switch: DB 0, Four 2, Ring 3.
- First critic round: 24 source-only GPU training runs, additive and structured full interaction, pure observed-count NLL, three seeds in all four LOSO folds. All checkpoints frozen on source-family validation before target scoring. Source-heldout controller-flip direction: additive 28/45, full 20/45; full context shuffle NLL +0.004 on average and score changes small. Conclusion: context tensor present but model has not learned reliable controller effect.
- Minimal correction: same full architecture and source data, add confirmed matched-controller B15 contrast loss on exactly the same state and eta. Source-heldout flip direction rose to 28/45, but the median probability response remained about 0.011. All checkpoints were frozen before target scoring.
- Frozen LOSO diagnostic: Toy additive/full/contrast B15 = 42/31/34 of 48 (eta-only 42); DB = 24/23/13 of 24 (eta-only 14); Four-Way = 23+1 unresolved/23+1 unresolved/24 of 24 (eta-only 24); Ring = 17/0/1 of 60 (eta-only 27). Additive cannot change eta ordering within a state, so its DB result is not evidence for learned state–eta interaction. Ring contrast still has 59 severe high-confidence false positives. Target context/state shuffle did not change top-1 B15; controller information is not yet used for deployment selection.
- Post-hoc support audit after frozen LOSO: all 60 Ring target contexts have at least 3/10 nominal H8 features outside the source 1–99% envelope (median 5), with median normalized nearest-source distance 4.64. This is a physical/controller context support gap. Because this target evidence has now been opened, future designs informed by it require a new independent confirmation cohort for any renewed strict zero-shot claim.
- H8 matched-intervention probe: eta-conditioned 24-feature context modestly improved held-out B15 flip directions versus nominal 10-feature context, but predicted controller probability changes stayed small and source validation score was not consistently better.
- H20 matched-intervention probe: all 253 existing pairs were recomputed using only a 20-step physical response (no task rollout); all contexts valid. On independent source families, nominal20 source-validation scores across seeds = 0.621/0.593/0.624; rich20 = 0.670/0.644/0.605. Rich20 correctly orders 6/7 Four-Way controller flips for all seeds and 3–4/5 Ring flips, but response magnitudes remain small (roughly 0.01–0.03). H20 is not a decisive interaction solution and did not use frozen target outcomes.
- The first balanced expansion submission failed on a missing human-readable protocol field before journal write; 12 first continuations were attempted but no outcomes persisted or used. Protocol fixed before any merged result; see balanced_expansion/preexecution_correction.json. All planned keys were rerun and merged.

Next gate: construct an intervention dataset with enough controller-induced eta-preference variation and independently held-out source families; separate a true preference-change signal from overall controller quality. Do not re-use opened LOSO target labels for model selection.

- Second compatible controller condition: same 48 source states and 192 exact eta pairs, replacing only future frozen Flow by DB primary 87.5%, Four-Way v10 wide, Ring v7. Preflight 3,072 requested / 0 exact / 0 partial / 0 aggregate / 3,072 genuinely missing. All 3,072 continuations journaled and merged. Postflight: 3,024 exact, 45 partial, 3 numerical unresolved; no Q16 imputation. A post-execution edit changed only the analysis function in `second_variant.py`; execution used the frozen `intervention.py` hash recorded in the protocol and did not change during jobs. Ring canonical→second has 13 interval-certified eta-ranking reversals; DB and Four-Way have zero under this particular comparison. Across all controller pairs, source TRAIN has 45 certified reversals and source VAL has 9.
- Unseen third-controller test of two-controller H20 models on held-out source families: Ring oracle B15 in 2/4 states; nominal H20 selected 0–1/4 and rich H20 selected 0/4. Wrong-controller context did not rescue selection. This is source-side controller transfer, not a LOSO target result.
- Three-controller matched training: full H20, true eta-independent additive, bounded-residual logit 1/3, and explicit certified controller-eta reversal constraint, all three seeds. The first attempt at an “additive” control incorrectly received eta-conditioned context; it is retained and explicitly marked invalid. The corrected additive baseline receives only nominal C(h). On independent Ring source families aggregated across three seeds and three controllers: full 5/24 B15, corrected additive 11/24, bounded1 6/24, bounded3 1/24, bounded3 plus interaction loss 10/24; oracle 24/24. Correct-context versus matched wrong-controller selected B15 was unchanged in Ring for the full and interaction models. Among 3 interval-certified Ring VAL reversal cases, full predicted both rankings correctly 0/9 seed-cases, bounded3 interaction 1/9. Thus training recognized some controller-wide quality changes but did not reliably learn controller-dependent eta preference.
- Non-neural local control: 464 full-Q16 matched TRAIN controller-conditions, 156 held-out source conditions. On Ring held-out conditions, same-scene eta-only k=1 selected 6/8 B15-available state-controller groups; eta+H20-context k=1 selected 5/8. Context is not giving a stable local advantage; exact eta repetition makes this a diagnostic, not unseen-proposal evidence.
- Direct context alias audit: in Ring 137 complete matched-controller Q16 comparisons, 30 had absolute Q16 change >=0.75. Of those 30, 24 had normalized H20-rich context distance <0.25; context distance versus |delta Q| Spearman -0.05. A source-only H100 nominal response (100 steps, <15% of task horizon) still had 23/30 such aliases and Spearman -0.12. A common-trajectory short Flow/safety function signature had 22/30 and Spearman -0.03. These specific compact summaries therefore do not resolve controller-conditioned feasibility, despite separating some controller-swap inputs numerically.
- Explicitly post-hoc target-label diagnostic, never called zero-shot: fine-tuning the source-only Ring critic on 2/8/32/64 Ring TRAIN families (519/2,097/8,412/16,865 canonical pairs; Ring VAL checkpoint selection) moved frozen Ring K16 B15 to 44–47 / 44 / 45–46 / 47 across three seeds. A Ring-target-supervised eta-only MLP on the exact same family subsets achieved 47 / 47–49 / 48–54 / 48–50. Two Ring states already repair most of the source-only 1/60 disaster, and state-aware adaptation does not surpass a scene-specific eta preference. The already-opened K16 TEST makes this causal diagnostic, not a fresh strict zero-shot confirmation.
- Final research gate: no tested controller-conditioning yields stable source-heldout eta ranking with useful context-ablation effect, and no state-aware source-only model reliably exceeds eta-only on the frozen fourfold LOSO. This constitutes a principled negative for the current four-scene support and tested deployable controller contexts, not a theorem that no possible richer controller representation can transfer. Generator remains frozen; no manual mode IDs or changed safety/success semantics.
