# 一、论文定位与本轮问题

**论文定位（用户确定）：**
- 修正黑盒 controller 在安全层下出现的死锁，不论死锁成因；安全层是设定，不是假定的成因。
- **黑盒：** 方法不依赖 controller 已知的控制律公式，只探查它的行为。学习得到的模型、模型预测控制、A* 一类规划器都算黑盒。手写的闭式规则（朝目标直走、势场等）不纳入。
- **衡量死锁是否被解决：** 与已有文献一致，用成功率相对 safety baseline（只加安全投影、不加修正）的提升来表示。不需要另建正式的死锁判据。碰撞率、超时率、unknown 率照常报告；timeout 仍不得直接称为 deadlock。

**已有结论（round32–37）：**
- 修正（时间表）在学习型黑盒（Ring Flow、高斯行为克隆策略、学生）上远胜持续右手规则。
- 但在分布式模型预测控制 controller 上，持续右手规则 100%，时间表约 80%，持续右手规则显著更好。
- 两种方法各有适用的 controller，所以方法的完整形式应当是"在时间表与持续右手规则之间选择"。

**本轮两个问题：**
1. **更多黑盒族：** 在 6 个新的黑盒 controller 族上，修正是否仍然有用？哪些族偏好时间表，哪些偏好持续右手规则？
2. **把持续右手规则加进动作菜单：** 在已有族上训练的扩展选择模型，能否对没见过的族零样本选对？少量 pilot 标签的选择要多少条才够？
