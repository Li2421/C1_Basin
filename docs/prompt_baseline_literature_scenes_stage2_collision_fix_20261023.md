# 一、问题（开工时用 v2 的 raw 自己复核）

v2 第二阶段碰撞局的比例：

| 场景 | 只加安全投影 | 加修正后 |
|---|---|---|
| 圆形围场 | 38% | 62–67% |
| 二维拥挤随机 | 12% | 17–19% |
| 窄通道 | 9% | — |
| 门口 | 0 | 0 |

重叠都很小（圆形和窄通道 95% 以上不到 1 毫米，二维拥挤随机最大 1.2 厘米），但碰撞判据的余量为 0，所以都计为碰撞。原因有三：

1. **窄通道、二维拥挤随机：** 论文前向欧拉中 p_{k+1} = p_k + Δt·v_k，本步加速度改变不了下一步位置，而二阶约束只在采样时刻成立。窄通道的碰撞局全部发生在采样时刻约束都满足的情况下。
2. **没有余量：** 安全距离正好等于两半径之和，采样之间和数值误差造成的微小重叠都会计为碰撞。
3. **无解时的处理：** "对全部约束行最小化最大违反"会把违反分摊到配对约束上。二维拥挤随机 99.6% 的碰撞局、圆形 68% 的碰撞局之前已有约束违反。

门口场景的约束直接作用在下一个前视点上，半径也有膨胀，0 碰撞，不需要改。

# 二、只改安全层（窄通道、二维拥挤随机、圆形围场）

1. **余量：** 安全层内的配对距离与墙距离各加 ε，ε = 1% × 该场景第二阶段的 d_safe（`CORRECTION_REVISION.md`：窄通道与二维拥挤随机 0.3001，圆形围场 4.0001）。碰撞判定、成功判定与物理半径不变。
2. **窄通道、二维拥挤随机：配对约束改为作用在本步加速度能影响的位置上。** 机器人 i 在第 k 步：
   - 先算 p̄_i = p_i + Δt·v_i、p̄_j = p_j + Δt·v_j（邻居信息与 v2 第二阶段相同）；
   - n_ij = (p̄_i − p̄_j)/‖p̄_i − p̄_j‖，g_ij = ‖p̄_i − p̄_j‖ − (d_safe + ε)；
   - 约束：n_ij·Δt·(v_i + Δt·a_i) ≥ −(γ/2)·g_ij。互惠、各承担一半，与 v2 相同。

   两台机器人都满足这条约束时，第 k+2 步的中心距不小于 d_safe + ε，第 k+1 步到第 k+2 步之间的连线上也处处不小于 d_safe + ε。推导与单元测试写入 `STAGE2_FIX.md`。

   **γ 的选取：** 在 {0.05, 0.1, 0.15, 0.2, 0.25, 0.3} 中取能通过第三节单元门第一项的最大值，逐场景写定。粗略的解析上界是 a_max·Δt/v_max（窄通道 0.3，二维拥挤随机 0.225），以单元门为准，不按 rollout 结果调。
3. **圆形围场：** 二阶约束的形式与参数（l0 = 6、l1 = 5）不变，只加第 1 条的余量。
4. **无解时的处理（三个场景）：**
   - 先保持配对与墙约束不变，只放松速度约束；
   - 仍无解，再对配对与墙约束最小化最大违反；
   - 加速度上限照旧不放松；违反照旧逐步记录，不记为 unknown。

**不变（逐项明确）：** state、合格实例、seed 0–1；四种做法（只加安全投影、全程 η10、全程 η13、人定双 η 广播进度切换）；动力学与积分方式；加速度上限；速度上限及其约束形式；圆形的 128 边形墙；跟踪层；修订修正语义与 R_c；死锁判据的定义（逐机器人锥残差改用新约束中实际起作用的行）；统计方法与报告格式。
