# 一、上一轮的结论与本轮问题

**论文定位（用户确定）：** 修正黑盒 controller 在安全层下出现的死锁，不论死锁成因。黑盒指方法不依赖 controller 的控制律式子，只探查它的行为。死锁是否被解决，用成功率相对 safety baseline（只加安全投影、不加修正）的提升来衡量。timeout 不得直接称为 deadlock。

**round39 的结果：** 7 个族共 28 个行为克隆策略，在合法留出几何上没有一个通过导航能力门（要求 ≥ 15/16，最高 13/16，只有十字路口族接近）。失败几乎全是撞墙。用户审阅后确认的原因：

# 二、导航场与专家（全部写在本轮目录）

**导航场（新写，配单元测试）：** 每个 episode 在 reset 时，为每个机器人的目标计算一次导航场，之后整局不变：
- 在 0.05 m 栅格上，以 `Geometry.valid_points` 为可通行区域；
- 每个格点到最近墙的余量 c = 到墙距离 − 碰撞边距（碰撞边距 = `agent_radius + wall_radius + wall_collision_margin`，与 `GeneratedGeometry.margin` 相同）；
- 从目标做 Dijkstra，边代价 = 长度 × (1 + λ · max(0, c₀ − c) / c₀)，c₀ = 0.15 m，λ = 4。参数写入预注册，不调。
- 结果是每个格点"沿远离墙的路线到目标的代价"。最窄的门（0.45 m）在门中心处只比碰撞边距多约 0.05 m，导航场在门里自然走中线，不要求处处有 0.15 m。

**跟随点：** 从任意位置出发，沿导航场下降方向（双线性插值的梯度，必要时退回 8 邻域最陡下降）走过弧长 s 得到的点，记为 `waypoint(p, s)`。到目标的剩余弧长小于 s 时取目标本身。实现成向量化函数，配单元测试（目标处、门口、墙角附近，以及与 `Geometry.path` 的长度对照）。

**导航专家：** 动作 = 朝 `waypoint(p, 0.3)` 方向、速度 `max_speed`，离目标 0.3 m 内线性减速；不考虑其他机器人。它取代 round39 的纯追踪专家；round39 的 `navigation_action` 只作对照，不再用于示范。

**专家门（必须通过才能采集示范）：** 每族在本轮全部训练几何上跑单机器人专家 episode（每个几何至少 32 个，起点与目标按 round39 的 `task` 规则生成），成功率 ≥ 99%，且不存在撞墙。不通过的族记为缺口，并报告最小余量的分布与失败位置图；不得通过修改物理、机器人半径或成功标准来通过。
