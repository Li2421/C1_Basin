# 一、为什么要修正（数字开工时自己从已有 raw、traces 与诊断复核）

**已经出现、与预期不符的四处：**

1. **窄通道场景被错归为"controller 级失败"。** 分布式下 44 个合格实例全部按"只加安全投影成功率 ≤ 5%"归为 controller 级失败，去除这些实例后的死锁候选变成 0。但同一批实例在集中式下成功率约 97%；分布式下 43 个实例出现逐机器人滤波器平衡点死锁（4a′）；停住的未到达机器人与最近邻的中心距绝大多数正好等于配对安全距离（0.3001 m）。这是安全层造成的失败，不是 controller 自身的问题。

2. **门口场景的修正增益不是解开死锁。** 两种安全层下都失败的 5 个实例：集中式路径积分采样第 2、3、5 个实例，集中式采样第 4、5 个实例（文件代号 centralized_mppi2/3/5、centralized_sampling4/5）。抽查的 10 局里，两台机器人都停在离目标 0.07–0.32 m 处，名义输入为零或很小，最后 50 步安全投影没有改写。两个目标只相距 0.2 m，这些 controller 自己不把两台机器人靠得那么近。全程 η10 修正把它们救到 100%，靠的是修正的朝目标分量，不是解开死锁。

3. **学习菜单不含三种固定修正。** v2 沿用 v1 封存的 12 个动作，里面没有全程 η10、全程 η13 和人定双 η 进度切换。结果是：

4. **修正在目标附近不收敛（下称"目标附近徘徊"）。** 修正基的相对分量（Brel）对其他全部机器人求平均，距离不限，而且已到达的机器人也照加。全部机器人都到了目标附近时，相对分量仍不为零，所以目标构型不是修正后闭环的平衡点：机器人在目标附近被推开，停在到达容差（0.08 m）之外。

   按局合并，"超时且全部未到达机器人距自己目标都不超过 0.24 m"的比例：

   | 场景 | 安全层 | 只加安全投影 | 全程 η10 | 全程 η13 | 人定双 η 进度切换 |

   | 二维拥挤随机场景 | 分布式 | 3.4% | 23.4% | 72.5% | 37.2% |
   | 二维拥挤随机场景 | 集中式 | 3.4% | 28.0% | 74.0% | 37.3% |

# 三、修正 2：修订修正语义——相对分量只在接触冲突时启用

## 3.1 定义

修正基三个分量的公式都不变：朝目标分量（Bgoal）、垂直分量（Bperp）、相对分量（Brel）。Brel_i 仍按第 28 轮 `local_basis`：对其他全部机器人先逐对取 bound(p_i − p_j, v_max)，再平均。唯一的改动是给相对分量加一个开关：

- **接触冲突：** 若存在 j ≠ i，使 ‖p_i − p_j‖ ≤ R_c，并且 i 与 j 不是同时都在各自的到达容差内，则机器人 i 处于接触冲突。"已到达"与原到达停止用同一判据（‖g − p‖ ≤ goal_tolerance），每步用当前位置计算。
- 处于接触冲突时，Brel_i 照原定义；否则 Brel_i = 0。
- **R_c = 1.25 × d_safe**，即两机表面间隙不超过约半个机器人半径。
  - d_safe 是该阶段安全层实际使用的配对安全距离：`shared_control/hard_projection.py` 中的 `d_safe`（2 × 半径 + agent_collision_margin + separation_buffer）。
  - 第二阶段门口场景用膨胀后的半径。
  - 逐场景、逐阶段的数值在第一条修订 rollout 之前写入新文件 `CORRECTION_REVISION.md`，之后不改，不按结果调。
- η 数值、两次投影、进度切换（含 6/7 时限回退）、跟踪层、到达停止全部不变。

## 3.2 依据（写入 `CORRECTION_REVISION.md`）

1. **开关覆盖了要解的死锁。** 在滤波器平衡点上，本机速度近零而配对行起作用，意味着 h_ij ≈ 0，即两机正处在安全距离上。已保存的分布式只加安全投影数据中，停住的未到达机器人与最近邻的距离不超过 R_c 的比例：
   - 窄通道约 99.5%；
   - 圆形围场约 94%；
   - 二维拥挤随机约 55%，其余停住时附近没有其他机器人，不属于机器人间平衡点。

   所以冲突期间的修正与原语义完全相同。例如窄通道论文 state 中，机器人 0 与两台挡路机器人相距 0.354 m，开关一开始就打开，挡路机器人照样被推开。
2. **目标构型成为平衡点。** 全部机器人都在容差内时没有接触冲突，相对分量全为零；朝目标分量只把机器人拉向自己的目标；垂直分量在安全速度为零时为零。目标构型因此成为修正后闭环的平衡点，这是任何任务进展条件的前提。
3. **开关在徘徊局里关闭。** 已保存的"目标附近徘徊"局的终止构型中，机器人两两距离都不小于约 0.48 m（二维拥挤随机的目标间距不小于 0.5 m），按上式开关全部关闭。
