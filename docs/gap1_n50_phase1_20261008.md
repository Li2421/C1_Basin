# Gap1 N=50 Phase-I audit (2026-10-08)

Status: **FLOW_COMPETENCE_FAILED**. Neither existing N=50 candidate meets the
non-opposing navigation gate. No N=50 checkpoint was frozen, no N=50 opposing
test was opened, and no eta Success-Basin data were generated.

## Executed nominal chain

The evaluated control is the candidate frozen-weight Flow sample integrated
for 10 Flow steps, bounded to the environment's 0.5 m/s maximum, set to zero
for agents already within the accepted 0.08 m goal tolerance, projected by
`CertifiedHardSafetyFilter(HardProjectionConfig())`, then passed to
`BottleneckEnv.step`. The at-goal guard and hard safety projector are the same
ones used for the accepted N=10 competence audit. There is no eta, critic,
generator, path coordinator, or yielding rule. The implementation is in
`bottleneck_family/evaluate_competence.py` and
`bottleneck_family/evaluate_safety_audit.py`; the projector is in
`diagnostics/double_bottleneck_eta3_basin/tools/exact_projection_retry.py` and
`shared_control/hard_projection.py`.

## Interpretation and gate

The models show some bottleneck throughput, but throughput is not task
completion. v4 loses previously achieved goal occupancy under dense traffic;
v5 often never reaches the goals. Sparse traces establish a Flow
goal-convergence failure even when the safety projector is effectively
inactive; dense traces add frequent safety intervention and insufficient
recovery. This is ordinary navigation/throughput failure, not a valid
opposing-agent safety deadlock baseline.

The N=2 and N=10 frozen checkpoint SHA256 values remain unchanged:
`7ea73d275ba3b928922cd68da24bf8b0c316c098d4e455050828acf8c0ecd6e5`
and `d062058c45e87c81a3c10f1f0c86523b111b90501a70f3230aa87b4c4918d980`.
Because N=50 failed the non-opposing gate, Phase II is prohibited in this
task. No opposing N=50 rollout or eta dataset was created.
