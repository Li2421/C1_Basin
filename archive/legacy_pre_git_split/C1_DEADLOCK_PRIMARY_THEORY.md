# 死锁优先的时间逻辑风险（研究候选，尚未完成验证）

场景专用导航势已删除。新风险只读取任务检测谓词及其物理阈值，
不包含地图节点、退让动作、专家回归目标或额外执行控制器。
通用核心接收任意维度的谓词轨迹；当前位置适配器支持 N 个主体、
D 维位置，但当前冻结 Flow-BC 实验仍是两个主体，不能据此声称
控制器已泛化到更多机器人。

## 数学定义

令 m_(t,j)>0 表示死锁检测的第 j 个必要条件成立。当前适配器使用
未完成任务、过去 W 秒各主体绝对目标进展小于阈值、当前各主体
速度小于阈值这三个归一化裕量。对有完整历史、包含 L 个实际动作
的窗口 w，定义 q_w=min_(t in w,j) m_(t,j)，rho=max_w q_w。
L=ceil(hold/dt)+1，与检测器从第一个候选动作开始计时一致。

使用温度 tau>0 的上近似：

    qtilde_w = -tau log(mean_(t,j) exp(-m_(t,j)/tau))
    rhotilde = tau log(sum_w exp(qtilde_w/tau))
    R_D = ReLU(1+rhotilde)

只纳入完整有效窗口，无完整窗口时 R_D=0。若每个窗口含 L*M 个
裕量，K 个有效窗口，则

    0 <= rhotilde-rho <= tau log(L*M*K).
    1_D <= R_D,   P(D) <= E[R_D].

证明使用 min(x)<=-tau log(mean exp(-x/tau))<=min(x)+tau log(n)
和 max(x)<=tau log(sum exp(x/tau))<=max(x)+tau log(n)。
总体期望约束才支持概率界；有限验证均值不是总体保证。
平滑仅发生在风险聚合，硬安全投影和原始事件终止不被平滑。
速度范数、绝对进展和事件分支仍是分段可微；精确对称静止状态
仍可能零梯度。此风险不保证全局脱困，不是校准概率。

平滑时间逻辑鲁棒性的相关原始研究：
https://arxiv.org/abs/2305.09116 。上述上近似及误差界在本实现中
明确给出并测试，不借用论文结论宣称当前 C1 训练已收敛。

## 流程与证据

保持 min J_def subject to E[R_D]<=epsilon，预步风险更新非负对偶。
第一轮预先固定 tau=.02、epsilon=.01、零残差初始化。
timeout 独立统计，禁止把减少 timeout 当成减少严格死锁。
死锁首次触发即终止；没有死锁恢复带来的成功计数变化。

旧开发验证 256 条轨迹中，旧死锁项的直接轨迹偏导每条死锁仅落在
一个时间步。新平滑聚合的非零偏导覆盖显著扩大，但这不是独立
控制变量的数量，也不是策略 BPTT 可优化性的证明。
20 秒前缀对未来死锁的 AUC 约 .45--.49，只有两个正例；不能证明
20 秒足够，也不能精确估计预测性能。完整轨迹 AUC=1 部分来自
风险直接对应检测定义，不当作提前预测证据。

一个按编号选择的已见死锁案例，8 步局部诊断中第 4 步成功，最终
独立原始环境回放在 608 步完成；碰撞、CBF 和速度违规均为 0。

## 完成任务的必要边界

死锁的反面不是任务成功。两主体在远离目标处持续绕圈，速度始终
超过低速阈值，满足 R_D=0 却永久不完成任务。单元测试显式保留
这个反例。若冻结 Safety 就具有这种行为，则 G=0 同时达到
J_def=0、R_D=0，是当前约束问题的全局最优；仅优化这两个量没有
理由改变它。此结论属于目标函数的限制，不是求导代码错误。

因此本候选只声明死锁事件上界，目标完成必须以独立闭环结果
验证，且不能用不适配新任务的冻结基线来制造优势。更大场景的
预检已经出现这种风险为零的 timeout；相关结果完整保留。
