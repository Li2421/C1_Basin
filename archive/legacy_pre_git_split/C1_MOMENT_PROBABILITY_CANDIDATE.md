# 显式候选：联合预测噪声的均值—方差风险

不新增学习模型，不更改冻结Flow、G_phi、双投影或原始—对偶目标。复用原事件的裕量定义，不复验旧的softplus/ordered等评分形式。新机制是多个未来噪声样本之间的矩耦合，而不是逐轨迹评分的简单变换或再取均值。

## 公式和批次上界

同一起点、当前phi下取K>=2个未来闭环，rho_i满足D_i推出rho_i>=0。定义

\[
 m=\frac1K\sum_i\rho_i,\quad v=\frac1K\sum_i(\rho_i-m)^2,\quad
 r=\frac{m}{\sqrt{v+s_0^2}},\quad
 R_K=\frac1{1+\max(-r,0)^2}+\log(1+e^r).
\]

s_0²>0是固定数值正则，当前内核默认1e-6，机器人参数尚未冻结。由单侧Chebyshev/Cantelli界，当m<0时，经验分布中rho>=0的比例不超过v/(v+m²)，加入正则增大该界；m>=0时第一项为1。softplus非负，因此每一个有限预测批次都满足

\[
 \frac1K\sum_i1_{D_i}\le R_K.
\]

只要各预测噪声具有规定原分布，对该批次再取期望就有P_phi(D|x)<=E[R_K|x]。此结论不要求把样本矩冒充总体矩，也不要求风险估计器或新控制规则；批次样本可相关，只要每个边际分布正确。用于精度和独立验证的采样仍应按协议独立。

单次R_K不是总体死锁概率的高置信上界，例如真实分布{-1,+1}等概率时，恰好抽到两个-1可能得到接近0的R_K。上述保证是批次期望，不是每次评分的置信保证。后续训练若使用R_K，原C1期望约束应显式包含K重噪声，而不是声称无偏估计了某个总体矩函数。

## 梯度机制及风险

第一项是矩信息给出的概率界；单独使用它在m>=0会恒为1。显式softplus项给标准化均值提供正导数，避免整个正均值区域没有优化信号。它增加保守性，不能宣称是精确概率或最紧界。

各rho_i的导数通过m和v耦合，区别于旧逐轨迹正权重变换。均值负时，减少方差会降低风险；均值正时降低标准化均值也可能通过增大方差实现，不必然降低真实死锁概率。小K方差估计不稳定、v接近0时风险可能很大；这些均需独立检验。上界不能保证相关性、概率排序或梯度脱困。

`single_integrator/c1/risk/moment_probability.py`仅实现显式矩运算。数学检查包括有限分布Cantelli上界、固定方差下非零均值梯度、样本耦合梯度差分、单次估计非置信证书反例和有限批次期望上界。没有接入主训练，没有开展此候选的机器人测试。下一步先检查完整原事件适配及梯度实现，再按约50案例的小预算检查预测和实际干预效果；不能以数学测试代替两项验收。

矩概率界的原始研究背景：[Generalized Chebyshev Bounds via Semidefinite Programming](https://web.stanford.edu/~boyd/papers/prob_bnds.html)。本文softplus延拓及批次实现为项目候选构造，不归为该论文的机器人算法或理论保证。
