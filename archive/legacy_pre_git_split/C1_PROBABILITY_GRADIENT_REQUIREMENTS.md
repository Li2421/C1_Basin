# 从“事件评分”到“概率梯度”的下一步审视

旧候选保持归档，不重新跑。当前未得到满足两项要求的R_risk；本文不是新候选已经通过的声明。没有启动GPU或训练。

## 不直接把CVaR当作新解法

[Chow等的CVaR工作](https://arxiv.org/pdf/1506.02188)给出尾部风险的变分定义，并研究其MDP优化。下面是针对本任务二值事件的独立推导，不是引用论文的机器人实验结论。

令D为有限时域原死锁事件，p=P(D)，尾部质量beta属于(0,1]。对L=1_D，

\[
\operatorname{CVaR}_{\beta}(L)
=\min_z\{z+\beta^{-1}\mathbb E[(L-z)_+]\}
=\min(p/\beta,1).
\]

故p<beta时梯度仅为原概率梯度的1/beta倍，p>beta时为0。单纯把二值死锁换成CVaR既不产生新的方向，也不修复有限样本梯度缺失。对连续严重度的CVaR可能改变方向，但“更关注严重度尾部”本身没有证明改善真实死锁概率；因此当前不启动这一替换的机器人实验。

## 起点预测正确仍可能给不出概率梯度

通用解析例子：Z服从标准正态，D_theta={theta+Z>0}。p(theta)=Phi(theta)，p'(0)=1/sqrt(2pi)>0。然而固定有限Z样本的二值事件均值几乎处处导数为0。样本平均与微分不能在这个不连续例子里直接交换。

一个对事件有上界的连续分段线性风险是R_h(rho)=clip(1+rho/h,0,1)。它在rho>=0时等于1，rho<0时小于1，但导数只在(-h,0)非零。theta=0、h=0.05时，每个预测样本落在梯度带的概率仅约0.01994；2、4、50个预测噪声全部错过该带的概率由(1-q)^K给出。`scripts/audit_c1_probability_gradient_limits.py`保存确切数值。这不是对真实环境的概率估计，也不重新测试旧风险；它说明仅增加事件对应证明不能解决少量预测噪声下的优化问题。

## 下一候选的必要说明

1. R仍描述当前G_phi闭环未来的原死锁事件，保留事件裕量/上界构造；不把对另一控制器或参数扰动分布的风险冒充当前策略风险。
2. 明确梯度来自事件边界附近的概率变化，还是来自死锁内部的严重度变化；不能将后者自动解释为前者。
3. 如提出条件积分或概率递推，须处理原死锁历史窗口/计时器状态、首次事件边界及硬投影导致的非光滑性；不能直接套用连续扩散控制定理。
4. 若增加外部critic、改变采样控制器或借候选路径选择获得结果，会超出当前实现边界，当前不采用。
5. 先以可计算的数学机制解释改进，再做每种形式约50个测试。通过独立预测与等幅梯度避锁之前，不完整训练。不把有限样本未显著当作数学不可能，也不把正向趋势当作验证通过。

这次审视只排除了一个缺乏新梯度机制的直接替换，并明确了后续推导必须补的缺口。尚无新的合格R_risk，完整目标仍未完成。
