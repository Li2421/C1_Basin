# 原事件边界包络＋防御性重要性采样（运行前冻结）

2026-09-18，新机制一次性筛查。不是已归档的二值概率小步长差分，也不是矩评分重命名。区分当前策略风险的定义、积分估计、实际动作方向三个层次。

## 事件关系与梯度

rho采用原strict/stalled首次事件的event_history裕量，模型续演仅计算风险，执行依原首次事件终止；安全模型续演与原阈值下D推出rho>=0。定义h=.1，z=clip(1+rho/h,0,1)，B_h(rho)=z²(3-2z)，R_h(phi|x)=E_{xi~N(0,I)} B_h(rho(phi,x,xi))。

逐轨迹1_D<=B_h<=1，故P_phi(D|x)<=R_h<=1；差值不超过P(-h<rho<0)，若无边界原子，h趋零时收敛原概率。此次h固定，不搜索、不声称等于真实概率。正侧完全平坦，梯度只来自安全侧事件边界带，不再推动死锁内部严重度。

若rho关于干预局部Lipschitz、几乎处处可微、导数有可积控制且允许期望与微分交换，则grad R=E[B'_h(rho) grad rho]；B'_h=6z(1-z)/h在(-h,0)，其余为0。仅用现有闭环JAX分支VJP得到候选方向，零残差第二硬投影的弱活跃点不保证存在普通梯度，不能无条件声称上述正则条件已满足。配对负方向检验必须过关；本实验不替换反向规则、不软化硬投影、不修改Flow。即使通过，也需后续参数导数/约束训练检验。

## 采样机制

每起点2个独立原噪声先导样本，求rho_i及全850×4噪声梯度g_i。用先导局部线性近似构造mu_i=clip_norm((-.05-rho_i)g_i/||g_i||²,2)，退化梯度给零中心。先导只构造积分提议，不参与风险样本均值、不选动作或路径。

q=.5*N(0,I)+.25*N(mu_1,I)+.25*N(mu_2,I)。另8个独立噪声，固定分层4/2/2个分量，全部纳入估计。权重w=p/q=1/(.5+.25 exp(xi·mu_1-||mu_1||²/2)+.25 exp(xi·mu_2-||mu_2||²/2))，0<w<=2。估计Rhat=mean(w B_h)，ghat=mean(w B'_h grad rho)。给定独立先导和冻结mu，分层估计期望仍是原噪声积分，导数不对提议求导；不把提议的分布变化引入控制器。不是自归一化权重，不clip Rhat，单批不保证Rhat>=总体概率。原噪声float32生成与加法有数值离散误差，上述密度恒等式为实数高斯模型，不能冒称浮点离散分布精确无偏。

防御性混合的背景：Hesterberg (1995), Weighted Average Importance Sampling and Defensive Mixture Distributions, https://doi.org/10.1080/00401706.1995.10484303 。本文事件包络和机器人协议为本项目构造，该文不提供机器人梯度保证。

## 数量与验收

25个独立closer_interaction起点，种子2026091901，每点2先导+8预测=250条完整预测及反传，含25次批次风险/方向计算。每点2个独立原噪声结局，50配对案例，参考/负/正/随机共200次物理回放。原Flow冻结、零初始化物理G_phi、双硬安全投影保持不变；未训练，不访问最终test。

前100步动作残差，投影后目标RMS=.0025、分量上限=.025；仅在2个原分布先导轨迹上匹配幅度，避免以提议噪声代替实际动作分布。梯度零时三干预均零，记录缺失方向，不能称其有用。无结局筛选，无候选路径选择，无学习模块。

统计沿用scripts/analyze_c1_event_history.py（仅分析，不执行旧风险）：25起点聚类10000 bootstrap；预测Spearman 95%下界>0、AUC下界>.5；负方向相对参考/正/随机死锁优势三比较调整下界>0、相对参考成功增益95%下界>0、原死锁至少半数转成功。难度、校准、安全门槛不变。额外报告边界带命中数、提议/原分布命中、权重ESS和非零梯度起点。不用代理下降/高AUC替代真实脱困。未过关则不训练，不扩大h/位移或换种子重筛。

GPU通过Slurm一次40分钟上限，物理回放累计30分钟上限。4个CPU内核测试（事件上界、权重恒等式、解析高斯边界导数、退化提议）通过才运行。
