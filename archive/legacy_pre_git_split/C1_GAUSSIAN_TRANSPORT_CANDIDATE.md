# 全噪声事件边界输运：公式可行性审视，尚未可接机器人

目标仍是当前G_phi闭环的原死锁概率，保留事件裕量/概率上界。此路径与固定一维噪声截面积分不同，使用全部原始高斯噪声坐标；没有改变控制器，没有候选路径选择。

[Warren和Allen的Malliavin weight sampling](https://arxiv.org/abs/1312.7480)提供不扰动原随机动力学而估计期望参数敏感度的研究背景。以下是本项目的有限维高斯推导；并未证明该文的条件适用于C1硬投影和事件检测器。

## 条件成立时的概率梯度

设xi为全时域标准高斯噪声，rho(theta,xi)>0等价于原首次strict/stalled死锁事件，theta为某个共享phi方向。固定c<=0，定义p_c(theta)=P(rho>c)，则p_0<=p_c。固定非负权重和为1时，R(theta)=sum_j w_j p_cj(theta)仍是当前死锁概率的上界；c=0时为原概率。这里R是对同一控制器原噪声的积分，不是对参数扰动控制器的风险。

令a=partial_theta rho、g=grad_xi rho。若rho足够光滑，g不退化，积分可微、输运场及散度可积且无穷远通量消失，则取v=a*g/(g^Tg)可得

\[
 \partial_\theta p_c=E[1_{rho>c}(xi^Tv-div_{xi}v)].
\]

推导：用事件边界的delta分布写参数导数，利用v^T grad rho=a，把导数转至高斯密度及v；高斯密度的对数梯度为-xi。与有限样本二值标签直接自动微分不同，这个权重项保留边界移动贡献。

设H为rho的噪声Hessian，h=grad_xi a、s=g^Tg，则

\[
 div(v)=(h^Tg+a\,tr(H))/s-2a\,g^THg/s^2.
\]

`single_integrator/c1/risk/gaussian_transport.py`实现这一点值权重，显式拒绝退化噪声梯度；没有用epsilon填分母。权重可以为负，它是梯度估计因子，不能当非负风险值或证书。

## 已验证与明确反例

5项CPU解析测试：仿射高斯事件概率梯度、与固定一维截面正交的事件、rho=theta+x+0.2*tanh(y)的曲面事件（包含散度）、混合参数导数及退化输入拒绝、非光滑接口遗漏反例。概率导数用独立解析表达和数值积分比较，不使用机器人样本。

反例尤其关键：rho=theta+|z|-1，theta=2时事件概率恒为1，真实导数为0。各光滑分支上g=sign(z)、H=0、v=sign(z)，若只用分支自动微分，公式错误地得到E|Z|=sqrt(2/pi)。正确散度还包含接口的2*delta_0。噪声梯度几乎处处非零仍不足以保证普通分支Hessian可用。

因此不能把这一点值内核直接套在当前min/max事件裕量、截断和硬投影上：必须补齐接口通量，或构造满足弱散度条件的输运场。原事件的参数不连续或噪声退化也需处理。直接依赖新投影方向导数仍不足以自动提供这些二阶/接口项。

## 当前决定

解析内核及反例留存用于约束后续推导；不启动此形式的机器人50例或训练，因为当前尚无符合条件的原闭环梯度实现。不能将有限维光滑例子的成功冒充C1概率梯度无偏，也不通过软化安全投影、添加控制噪声或外部critic绕过问题。没有重验归档风险。下一步仅在能给出接口处理与可控计算量后，才进入该新机制的机器人检验。
