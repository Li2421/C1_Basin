# R_risk 两项先验检验（2026-09-18，v1）

按用户最新要求，保留 ordered event-margin 上界公式和冻结Flow-BC、G_phi、双硬投影。两项通过之前不启动新的完整训练，也不添加路径候选搜索、退让规则或几何势函数。Job43为此前已启动的固定优化器诊断，只完成原16步预算，其结果不替代以下检验。

## 被检验对象

当前结构的零初始化G_phi（输出为0）作为明确冻结的起始策略，预测和实际回放均运行这同一个闭环控制器。这样直接检验训练起点的风险梯度，且保留有足够死锁的Safety难度；不能外推到所有训练后的phi。已有Job33独立噪声相关性作为开发证据，本轮仍重新测量。

风险是在t=0、尚未看到真实未来噪声时，使用4个预测噪声完整推演原42.5秒闭环，取当前ordered风险均值。不是只使用前5秒轨迹评分，也不是利用实际结局回算风险。它上界所定义的有限时域死锁概率，并非校准概率或无限时间死锁证明。

25个新均匀起点，起点生成seed=2026091850，rid从60000起；预测噪声82610–82613，独立结局噪声82620–82623。4组×25起点×4结局噪声=400条实际回放，另外100条预测求导；不打开保留的正式test。所有组共享配对结局噪声。

## 检验1：提前预测

每个起点的预测风险对照独立4次原策略结局的死锁频率。按起点聚类bootstrap，报告Spearman、按结局计的AUC、分组频率和零风险漏报，不只检查同轨迹R>1。先验要求：原策略死锁率至少10%、至少5个死锁起点；Spearman双侧95%区间下界>0且AUC下界>0.5。小样本无显著性即未通过，不能改门槛。

## 检验2：动作梯度用途

直接对前100步（5秒）的候选物理动作偏移a求 d E[R]/da。偏移加在G_phi输出之后、第二次原硬投影之前；前后所有控制仍由同一个闭环策略生成。a=0求导，构造负梯度、正梯度、独立随机方向三组；原策略为第四组。偏移是一次冻结的诊断干预，不是新增部署控制器，不挑候选轨迹，不按真实结局挑方向或调幅。

三种非零方向分别按原预测轨迹的同状态、同噪声投影后动作变化RMS标定至0.0025m/s。标定只调用单步投影并求幅度，不比较路线或风险。候选动作偏移每个分量绝对值上限0.025m/s；达不到目标或梯度为零必须显式报告，不能加启发式。零梯度起点三种偏移均为零，保留在总体统计中。

独立回放另外测量各组在各自访问状态的“加偏移前后投影动作差”，避免把状态分岔当作干预幅度。非零梯度起点上，三组总RMS须在共同均值±10%以内；不满足即幅度匹配未通过，不能声称排除了幅度混淆。标定RMS也须达到目标±1%。

按起点配对bootstrap，同时比较负梯度相对原策略、正梯度、随机的死锁减少量；三项使用Bonferroni校正后的双侧98.333%区间，均须下界>0。负梯度成功率相对原策略的95%区间下界须>0，原死锁转成功至少50%。timeout单列；不能用死锁转timeout替代脱困。所有原安全审计须零违规。

只有两项及幅度、难度、安全检查全部通过，才进入完整共享G_phi训练准备；通过也只是局部动作诊断，不等于参数梯度有效、训练成功或跨场景泛化。失败时按数据定位预测、方向、幅度或统计功效问题，禁止自动增加训练规模。

## 实现前置校验

新增offset接口必须在零偏移时与原物理executor逐步一致；非零偏移与可微前向在同噪声下比较首事件及轨迹，保留浮点差异。未通过前不启动400条正式开发回放。源码、参数、协议、噪声种子和分析脚本在回放前冻结。
