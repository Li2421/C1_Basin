# 终末时序进展候选：未验证控制效果

## 开发依据

Job35早期负梯度的4条死锁转普通timeout中，1条最后10秒确有明显目标进展；另3条的两个机器人净进展分别仅约(0.0309,0.00181)、(0.0239,0.00202)、(0.0394,0.00124)米。其中第二个机器人还移动约0.15至0.16米，但目标距离仅改善毫米量级。短暂速度脉冲使持续低速谓词不成立，不能据此判断有效脱困。完整数据和trace哈希见 `results/c1_early_gradient_v2/timeout_mechanism_audit.json`。

这些样本只用于发现机制，不改它们的原标签，也不把它们作为新候选的独立确认集。

## 公式

设 b 是当前 ordered 原死锁风险。复用已有 hold_seconds=5秒作为终末观察窗口W；复用原 progress_epsilon/progress_window_seconds 作为进展速率阈值v_p。令 e_i(t) 为原环境已有的目标误差观测：

```
p = max_i [e_i(T-W)-e_i(T)]
z = 1 - p/(W*v_p)
h(z) = (1 + z/sqrt(1+z*z))/2
g = 0.5 * h(z) * 1_{原终止为timeout或死锁且历史足够}
R_new = b + |1-b| * g
```

固定weight=0.5，未进行超参数搜索。这里没有构造场景空间势场、路线节点、退让方向或额外控制器；只对已有时序进展信号评分，并沿R_new实际前向函数求导。时间窗口用before起点与after终点精确覆盖W；普通timeout仍单独报告，不更改死锁定义。

当0<=b<=1时，R_new=1-(1-b)(1-g)<=1；当b>1时，R_new=b+(b-1)g>1；并且R_new>=b。因此原事件评分顺序与 1_D<=R_new、P(D)<=E[R_new] 保留。成功终止不启用额外项。

对非切换点，dR_new/db=1-g（b<1）或1+g（b>1），均为正；dR_new/dg=|1-b|>=0。h'(z)=1/[2(1+z²)^(3/2)]>0，所以在活跃agent与门控固定的分支上，增加净目标进展会降低额外风险。相比仅看速度，该项不会因增加往返路程而自动下降。它仍可被“只在终末窗口取得少量进展”等行为规避，不是最终完成定理。

## 必须保留的限制

- R_new>=b，因此可行约束更保守，可能更难达到epsilon。不能以修改epsilon掩盖不可行。
- 这不是空间导航势，但进展梯度仍可能偏好局部接近目标、不能引导必要退让。不能把单调导数当作可脱困证明。
- 首事件终止、max和门控仍有非光滑/不连续问题，未证明期望路径梯度无偏。
- 死锁概率上界仍针对原有限时域操作性判据；普通timeout的这个次要项没有概率证书。
- 仅通过4项CPU公式测试：排序/上界、不符合门控时不变、真实导数有限差分、死锁分支仍有额外进展梯度。尚未接入trainer或进行新闭环实验，不宣称改善。

模块：`single_integrator/c1/risk/terminal_progress_guard.py`。后续必须用新协议检验独立噪声下真实死锁转成功，并检查预测下降与实际下降的差距；原C1冻结Flow-BC、物理残差、双硬投影及原始—对偶目标保持不变。不恢复历史几何势函数/完成门控模型。

## 完整轨迹审计及新开发实验

CPU审计已见400条Job35轨迹：69条死锁最小新分1.5730，331条非死锁最大0.9797，排序保持；成功轨迹新增项为0；12条变长轨迹的无效padding替换不改变评分。普通timeout平均风险0.7510→0.7760，停滞死锁平均4.9267→6.5636，成功平均0.01694不变。保守性增大明显，不能把升高分数当成控制改善。原始报告 `results/c1_guard_trace_audit_v1/report.json`。

Job41、`results/c1_guard_factorial_v1` 固定20新均匀起点×4新独立结局噪声×5方法=400条真实回放。方法为Safety、ordered固定步、ordered回溯、guarded固定步、guarded回溯。风险与步长方法作2×2对照；均只执行前5秒干预。每起点两预测噪声与结局噪声分离；40组梯度均值（80次梯度rollout），至多480次预测风险前向计算。回溯从原.005线性残差RMS步长开始至1/32，只接受真实预测平均风险下降，否则原样返回；没有从评测噪声或路径池选解。

每起点保存实际参数树、协议及源快照，明确仅逐起点诊断，不能当作共享训练checkpoint。真实回放预算30分钟、整体Slurm上限1小时，完成后自动分析。开发门槛预先固定：Safety>=10%死锁及>=5独立死锁起点；新风险回溯相对Safety死锁差聚类区间排除0，成功数增加，原死锁>=50%转成功。该门槛低于完整目标的最终门槛，只用于判断是否值得进入共享训练，不等于总体目标成功。分析的合成数据检查确认死锁转timeout不会通过门槛。
