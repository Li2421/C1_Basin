# 起点条件风险与 C1：已成立和待证明的部分

本说明不增加控制规则、几何势函数、候选路径筛选或标签回归。策略仍为冻结 Flow-BC、物理残差 G_phi 与原双硬投影，原始—对偶目标不变。

## 条件概率对应

固定策略 phi、起点 x，令 xi 是声明的模型噪声，tau_phi(x,xi) 为执行原首事件语义的闭环轨迹。D 是原严格死锁或原终末停滞事件（普通 moving timeout 单列）。若逐轨迹 1_D <= R，则条件期望保序：

```
q_phi(x) := P(D | x, phi) <= r_phi(x) := E_xi[R(tau_phi(x,xi)) | x, phi].
E_x[q_phi(x)] <= E_x[r_phi(x)] = J_live(phi).
```

这个对应比同轨迹标签分类多了一层，但仍是上界，不保证不同 x 的 r 排序与 q 排序一致，也不保证两个策略之间 r 降低意味着 q 必然降低。平均起点约束也不等于每个起点都满足 epsilon。

独立同分布 K 个预测噪声下，样本均值 r_hat_K 对 r 无偏，条件方差为 Var(R|x)/K（需有限二阶矩）。这不把 r_hat_K 变成 q 的有限样本上置信界，也不使 r_hat_K 成为校准概率。只对同一生成策略重复模拟并取平均，没有选择某条预测轨迹执行。

固定总预算 N=B*K，以 B 个独立起点、每个 K 个独立噪声估计 J_live：

```
Var(J_hat) = Var_x(r_phi(x))/B + E_x[Var(R|x)]/(B*K).
```

因此用更少起点换更多每起点噪声，未必改善全局训练估计方差；不能仅凭条件评分较稳定就把训练 batch 改成大量重复少数起点。起点预测实验和训练采样优化是两个问题。不给困难样本额外权重，不事后筛选噪声。

## 梯度缺口

在可微分且可交换求导与期望的条件下，可以写 grad_phi r = E[grad_phi R]。当前实现有 min/max/ReLU、投影活跃集切换、首事件终止和 terminal-timeout 分支，不能未经检查直接套用该结论。

特别是首事件改变时，执行时域和参与评分的事件可能改变；逐样本自动微分对既定分支求导，并不自动包含随机变量空间中移动事件边界的贡献。有限差分或单条轨迹的小扰动通过，也不足以证明总体期望梯度无偏。当前精确/ordered 候选只声明分段路径导数与事件上界，未证明 C1 的随机优化收敛条件。

后续需要在固定公共噪声组上检查：多尺度中心有限差分与平均路径梯度的方向一致性；独立噪声组上风险与死锁变化；早期限定干预与全程干预分离。若发现终止分支引发系统性梯度失配，应解决风险/求导机制，不能偷偷更改原评测终止语义或把死锁后恢复计为成功。

## 当前开发实验

`scripts/probe_c1_conditional_risk_cpu.py` 在首次回放前写 protocol：40 个均匀新开发起点，每个 4 个预测噪声与 6 个独立结局噪声，合计400条；固定 Safety（零残差）以及 CPU backend。不按结局选起点，不使用预留独立 test。

`scripts/analyze_c1_conditional_risk.py` 同时报告 K=1、K=4 对六次结局死锁频率的 Spearman 相关、对结局事件的 AUC、起点聚类 bootstrap 区间、零评分下漏报和完整结局分类。置换检验只作开发描述，不把两个预算的未校正显著性当作论文确认结论。Safety 难度门槛沿用 >=10% 死锁且 >=10 个独立死锁起点。

这只能支持或反驳已固定策略下的起点风险关联；不能证明 C1 训练改善、跨策略泛化、跨场景泛化或提前动作干预成功。

## 补充原始文献核查（2026-09-18）

Nemirovski 与 Shapiro 的 [Convex Approximations of Chance Constrained Programs](https://optimization-online.org/wp-content/uploads/2004/12/1033.pdf)，第2节讨论用非负生成函数的期望构造保守概率约束，式(2.7)包含 `[1+z]+`。这给精确margin风险的概率上界提供了已有方法脉络；不能把文中的凸优化结论移植到本项目非凸神经策略，也不意味着当前ordered指数组合得到该论文的最优性保证。

Suh 等人的 [Do Differentiable Simulators Give Better Policy Gradients?](https://proceedings.mlr.press/v162/suh22b/suh22b.pdf)，ICML 2022，分析一阶仿真梯度在不连续/陡峭系统中的偏差与方差，包括样本中常见零梯度但总体导数非零的现象。这支持把“能自动微分”和“有限样本中能有效优化期望目标”分开审计。

对本项目的推断（不是文献已证明的项目结论）：零风险批次、事件分支切换可能与上述问题有关，需要用当前早期干预结果和之后的期望有限差分检查证伪。暂不引入该文混合梯度算法，不用未经定义的替代反向梯度，也不修改原安全约束。以上文献都不能替代独立闭环结局、多种子训练和扩展场景证据。

## 独立测试能支持多强的概率结论

固定策略、独立同分布Bernoulli结局、n次零事件时，单侧95%精确上界由 `(1-p)^n=0.05` 得到 `p_upper=1-0.05^(1/n)`。100次为2.951%，200次为1.487%，至少299个独立零事件样本才低于1%。数值保存于 `results/c1_zero_event_confidence_audit.json`。

目前预留400次配对执行是100个起点×2噪声×2策略，每策略只有100个独立起点簇，不能套用n=200的独立Bernoulli界。可把每簇任意一次死锁作为保守事件，其概率上界同时约束单次轨迹事件，但更保守。若以后要明确声明总体死锁率<=1%，必须使用足够独立样本及相应置信方法；不能从validation均值<=epsilon或零次观测死锁直接推断。

这不阻碍400次规模下检验相对Safety改善，二者是不同主张。多场景/多训练种子的联合概率声明还涉及多重比较，单格95%区间不是所有实验格的同时95%保证。当前不增加测试规模或打开预留test，仅记录最终声明所需证据。
