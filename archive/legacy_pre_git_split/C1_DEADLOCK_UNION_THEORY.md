# C1 原死锁定义的联合风险

本版本补齐原报告中的两个互斥死锁标签，不修改环境终止逻辑，不把所有 timeout 改名为死锁。模型、物理残差、两次硬投影、最小干预目标及原始—对偶流程保留。

令 D 为 first-event 严格死锁，S 为原 `classify_timeout_trace` 定义的终局停滞死锁。S 仅在原事件为 timeout 时成立：最后 round(2/dt) 个动作后的状态样本中，所有智能体速度小于 0.05，各智能体首末目标误差差的绝对值小于 0.02。保留原实现的样本端点语义；dt=0.05 时误差差对应 39 个时间间隔。普通 timeout 单独报告。

严格死锁沿用 `C1_DEADLOCK_PRIMARY_THEORY.md` 中的时间窗口上界 R_D。终局窗口各原子谓词写成无量纲裕量 m：速度项为 1-speed/0.05，进展项为 1-|error_end-error_begin|/0.02。令 N 为有效原子数，τ=0.02，定义

    q_S = min_j m_j
    q̃_S = -τ log[(1/N) Σ_j exp(-m_j/τ)]
    R_S = 1_{原终止事件为 timeout 且样本足够} ReLU(1+q̃_S)
    R = R_D + R_S

有 q_S ≤ q̃_S ≤ q_S+τ log N，故 1_S ≤ R_S。结合 1_D ≤ R_D，逐轨迹有

    1_{D ∪ S} ≤ R_D + R_S = R,
    P(D ∪ S) ≤ E[R].

使用非负上界之和，不以 max 聚合两个风险，避免一项较大时完全屏蔽另一项的导数。原流程优化 J_def + λ(E[R]-ε)，λ≥0；有限验证集上的平均风险满足 ε 只代表该验证集可行，不自动给出总体置信保证。

timeout 门控来自权威 first-event 事件码并停止求导。它使风险对成功轨迹不施加终局停滞惩罚，但事件边界不连续；反向传播是固定事件分支内的路径导数，不能声称是事件概率期望的无偏梯度。严格风险仍可能在精确对称静止点出现零导数。风险不是校准概率、也不是只看前 20 秒的未来死锁预测器。

这两个事件上界不涵盖全部失败：远离目标持续运动但无进展的普通 timeout 可以得到 R=0。若该基线同时 J_def=0，单独此约束不会强迫它完成任务。因此完成率、总失败率、安全指标与死锁到成功的配对转化必须独立验收；不能把逃离死锁定义但转为 timeout 当作目标达成，也不能声称该风险本身保证所有任务的活性或神经优化全局收敛。

历史审计使用已见的 384 条轨迹，不触碰新测试集。Safety 的 26 条严格死锁、25 条停滞死锁，及历史 Pg 的 27 条严格死锁，全部满足联合风险≥1，独立轨迹偏导范数均非零。原严格风险在 Safety 的 25 条停滞死锁上全部小于 1。新联合风险也在 14 条普通 timeout 中的 2 条给出≥1，符合“上界”而非准确分类器的性质。历史 Pg 的 4 条普通 timeout 风险为 0，直接显示上述完成性缺口。

证据：`results/c1_deadlock_union/historical_audit.json`。轨迹偏导不是控制参数的完整反向传播导数；实际可优化性需独立训练及真实环境配对验证。既有 `deadlock_primary` 运行源码与检查点不改变，保留为严格死锁分量实验。
