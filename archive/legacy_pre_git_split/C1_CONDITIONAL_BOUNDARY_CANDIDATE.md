# 条件事件边界积分：机制准备，尚不是已验证的机器人风险

旧候选归档不重跑。本路径研究如何对当前G_phi闭环的噪声作积分，补入事件边界移动产生的概率导数；不改变控制器、不添加外部critic、不选择候选控制路径。

## 文献与适用边界

[Feng和Liu的Conditional Monte Carlo](https://arxiv.org/abs/1603.06378)研究不连续被积函数的敏感度估计；[Lee等的非光滑模型重参数化梯度](https://proceedings.neurips.cc/paper_files/paper/2018/file/b096577e264d1ebd6b41041f392eec23-Paper.pdf)显式区分区域内部项和边界项。它们支持调查边界梯度这一机制，但其假设尚未在本C1闭环中证明，不能直接移植无偏性或收敛结论。

## 当前控制器下的条件概率

将原高维标准正态预测噪声xi沿固定单位方向w分解为xi=eta+zw，z服从标准正态且独立于eta。w不能依据正在积分的同一xi随意选择；否则独立性可能失效。控制器参数phi及原物理环境保持不变。

令rho(phi,eta,z)为与原strict/stalled死锁事件对应的裕量。假设固定eta时，事件{rho>c}在z轴上**完整地**表示为不相交区间并集(a_k,b_k)，则

\[
 q_c(phi,eta)=\sum_k[\Phi(b_k)-\Phi(a_k)],\quad
 \nabla q_c=\sum_k[\varphi(b_k)\nabla b_k-\varphi(a_k)\nabla a_k].
\]

若端点为固定阈值c处的简单根，且局部裕量可微，

\[
 \nabla a_k=-\partial_phi rho/\partial_z rho,
\]

b_k同理。正负无穷固定端点贡献为0。相切根、区间出生/消失、离散分支跳跃不能直接使用该公式。

q_0是条件事件概率，E_eta[q_0]=P(D)。如保留负侧事件裕量上界，可固定c_j<=0、正权重w_j和为1，定义

\[
 R(phi,eta)=\sum_j w_jq_{c_j}(phi,eta),\qquad
 P(D)\le E_eta[R].
\]

这是因为{rho>0}包含于每个{rho>c_j}，不需要把一个离散阈值加权和冒称为精确积分。具体阈值、权重尚未选定或验证；此处仅提供保持事件裕量/上界主线的构造。条件概率一般不等于某次未来结局标签，不能要求同一个起点的所有随机结局都由一个概率值完美排序。

条件期望可降低二值事件**评分**的方差（全方差公式）；并未因此证明边界**梯度**方差更小或C1训练收敛。实数正态模型与实际float32伪随机实现的差异也需保留说明。

## 已实现与未完成

`single_integrator/c1/risk/conditional_gaussian.py`实现给定完整区间时的高斯概率和移动端点导数。5项CPU解析测试通过：半直线真实概率及下降方向、双端点有限差分、多区间事件、极小尾概率/空集、不稳定根和非法区间拒绝。没有替代反向梯度，没有机器人效果结论。

当前缺少：原闭环事件区间完整性证明/可靠证书、原首次事件和硬投影边界处理、噪声方向选择的独立性保证、机器人上的独立预测和等幅梯度验证。稀疏扫描无符号变化不保证区间内没有两个根；根集合不完整会漏计死锁概率，不能称为上界。区间包络若确为事件超集则可给概率上界，但其导数是包络导数，不自动等于真实概率导数。

后续先解决区间证书的可实现性。未满足之前不启动机器人批量实验或完整训练。若需要控制器重设计、另加学得critic或路径选择器才能落地，则不采用此路径。每个可实施候选仍按约50个测试执行，不能以机制准备替代闭环验证。

## 追加审计：完整区间仍不足以保证整体概率梯度

`scripts/audit_c1_conditional_transversality.py`给出独立解析反例并用数值积分检查公式，结果保存于`results/c1_conditional_transversality_v1.json`。令Z、E独立标准正态，D_theta={theta+aZ+bE>0}，a²+b²=1。当a>0时，完整积分Z给出q=Phi((theta+bE)/a)，在theta=0有

\[
 E[\partial_\theta q]=1/\sqrt{2\pi},\quad
 E[(\partial_\theta q)^2]=\frac{1}{2\pi a\sqrt{a^2+2b^2}}.
\]

当a趋近0，真实概率导数不变，但条件导数方差发散。例如a=0.01时，即使每次条件概率完全精确，50个独立E样本平均梯度的理论相对标准误仍为118%。这只是解析模型的结论，不能用来估计机器人的误差。

更关键的是a=0时，完整区间为整条实线或空集，q=1{theta+E>0}；对几乎所有固定E，其参数导数为0，但整体概率导数仍为1/sqrt(2pi)。因此“各截面内没有移动根”不等于“整体概率梯度为0”。剩余噪声空间中的区域边界项仍可能存在，不能无条件交换E_eta与参数微分。原文的端点公式只说明固定eta、拓扑稳定且端点可微时的条件导数；还需要整体的微分交换条件或显式剩余边界项。

对已有50次机器人回放的缓存检查发现：5个截面的首步物理动作坐标跨度均非零（约0.00486至0.02097），故标签不变不能解释成噪声完全没有进入执行。沿各自共同轨迹前缀，位置坐标最大跨度约0.00343至0.03330；这些是闭环轨迹差异，不是同状态动作扰动幅度。这也没有证明存在上述正交边界，只排除了“所有回放实际相同”的解释。

决定：不追加当前固定随机一维方向扫描，不把它接入训练。若继续条件积分研究，必须先说明覆盖哪些事件边界、如何处理其余噪声方向的边界项，以及有限预算下的方差；简单换方向种子或加密网格不足以补齐理论。没有新增机器人回放，没有重验归档风险。
