# 原死锁概率的配对差分：小预算信号可实现性

这一机制直接将当前控制器的原首次strict/stalled事件概率p(phi,x)=E_xi[1_D]作为风险。在事件裕量rho正确对应D时，p=P(rho>0)，是事件上界取等号的情形。该风险值没有死锁内部严重度项，不是复验已有smooth_sum等归档形式。有限样本频率只是概率估计，不是自动成立的统计置信上界。

对固定参数单位方向d，以相同x、xi运行phi±hd，令Y=1_D(phi+hd)-1_D(phi-hd)。则E[Y/(2h)]=[p(phi+hd)-p(phi-hd)]/(2h)精确成立，无须对投影或检测器自动微分；但仅在p可微及h趋于0等条件下才逼近方向导数。有限h必须报告偏差风险，不能称为当前精确梯度或偷偷把邻近策略平均风险作为目标。

本次只检验是否有可观测事件变化，不据此优化phi或选择方向。25个新初始状态，每个正负两次，共50条完整执行。共享偏置方向由固定随机种子独立生成，h=0.0025，原始闭环全程使用该参数。此方向不是场景退让规则；同一噪声用于每对执行。原控制器、Flow-BC、双投影、时域、成功/死锁判据不变。

这25对估计的是任务分布平均风险的一个方向差分，不是每个起点的风险梯度，不足以证明早期预测或优于匹配随机扰动。其实际与Safety的偏移由原J_def记录，不假定正负投影后幅度完全相同。没有在此处做“负梯度更好”的效果比较。

分析须同时保留strict死锁、stalled死锁、成功与普通timeout。若无事件不一致对，样本差分和样本标准误虽均为0，也不能推出真实概率导数为0。信号稀少时不通过放大h、换种子重复测试制造梯度；先报告该小预算下的可辨识性。仅本机制通过后续独立预测和匹配梯度用途门槛才可能连接原C1训练。

文献背景：[Spall的SPSA说明](https://www.jhuapl.edu/SPSA/Pages/)讨论用两次目标观测构造随机方向梯度估计；本试验只有一个固定方向的中心差分，未实现SPSA训练，也不移植其收敛结论。

## Job55结果与停止决定

50条执行完成，正负两组均8/25 strict死锁、17/25成功、0普通timeout；25对中没有一对的死锁标签发生变化。原执行器安全检查通过。样本中心差分为0，没有可供当前估计使用的事件变化信号；不解释为真实梯度为0。

假设配对案例独立来自冻结任务/噪声分布，0/25不一致对的单侧95%二项上界为1-0.05^(1/25)，约11.29%。由|E Y|<=P(Y!=0)，只能给出该方向总体中心差分绝对值约22.59的宽泛上界。这不是无穷小导数界，更不是有用的梯度精度保证。完整结果、参数方向、源代码快照和全部执行轨迹保存在`results/c1_event_probability_difference_v1/`。

按预设规则停止当前小步长直接二值差分路线，不放大步长或换种子重跑，不启动训练。这个结果没有否定原死锁概率作为理论风险，也没有否定所有概率梯度估计方法；它说明当前25对直接差分没有可用样本信号。没有通过提前预测或梯度用途门槛。
