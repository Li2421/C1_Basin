## 1. 架构可表达，不等于优化必然成功

记同状态同噪声的冻结安全基线为 u_safe，可行控制集合为 A(x)。若存在控制 u*(x,xi)∈A(x) 能在期限内完成，则取 G*=u*−u_safe，有 Pi_A(u_safe+G*)=u*。因此加性物理残差和第二次投影本身不排除这样的解。

该命题要求能观测实现控制所需状态；有限宽度网络能否以足够精度表示、可行轨迹是否有安全和期限裕量、训练是否找到它，均需另证。安全集合中可能存在不可逃逸状态；冻结前缀也可能已把系统带入不可恢复区域。不得由此声称全局或所有初态可达。

当前 C1_SPEC 明确把风险称为 provisional，并未给出非凸原始—对偶算法的全局收敛定理。硬 CBF 投影给安全约束，不自动给任务完成保证。TRO 死锁论文的平衡点必要条件与特定 CLF 重塑方法的条件性结论，不能直接变成当前 Flow 残差训练的定理。

## 2. 一个不把 sigmoid 当概率的风险

设离散 SI 动力学 x_(k+1)=x_k+dt*u_k，固定期限 H=N*dt。V≥0 是状态势函数，单位为秒。成功后吸收，a_k 表示该动作是否在成功前或成功当步执行；死锁仍允许恢复，失败必须观测至期限。定义

    e_k = a_k [c*dt + V(x_(k+1)) - V(x_k)]_+
    B_T = sum_k e_k / (c*H - V(x_0)).

要求 c*H>V(x_0)。若期限内未成功，全部 a_k=1，故

    sum e_k >= c*H + V(x_N) - V(x_0) >= c*H - V(x_0),

即 B_T≥1。这对每条轨迹成立，不需要把观测结局额外加入损失，也不需要假定独立采样。

设 V 对最大单机器人位移是 L-Lipschitz：|V(y)−V(x)|≤L max_i||y_i−x_i||。环境死锁要求速度连续低于 v_low 达到 hold 秒；它还要求低进展和未成功，这两个附加条件不会削弱下面的必要条件。环境计时从首个候选动作开始，故所需连续动作数为 m=ceil(hold/dt)+1（整数边界按环境容差处理）。若 c>L*v_low，则每个低速动作满足 e_k≥(c−L*v_low)*dt。定义

    B_D = max_j sum_(k=j)^(j+m-1) e_k / ((c−L*v_low)*m*dt)
    R = max(B_T, B_D).

任何已发生的环境死锁（即使后来恢复）均有 B_D≥1。于是逐轨迹有

    1{出现死锁 或 到期未完成} <= R,
    P(出现死锁 或 到期未完成) <= E[R] = J_live.

因此**真实总体** J_live≤epsilon 才能推出这个联合事件概率≤epsilon。有限训练/验证均值满足阈值并不自动推出总体约束。碰撞仍应直接判为安全失败，不用风险分数掩盖。

## 3. 当前实现、代价和未解决条件

首个可计算实现为 V(x)=sum_i [||x_i−g_i||−r]_+/v_max，因此 L=2/v_max。默认 dt=.05、H=42.5、v_max=.5、v_low=.025、hold=5、c=.4。代码返回两个界、最大值、逐步欠账与期限裕量；裕量不正则返回无效结果，不能偷偷截断分母。公式有 max/ReLU 的分段可微性，不宣称处处光滑；成功分支仍沿用 C1 的事件掩码，不能据此宣称总体事件梯度无偏。

这是事件风险的**上界**，不是校准概率。界越保守，epsilon 越难实现。普通慢行或暂时远离目标也可能产生欠账；因此几何绕行需要正确的导航势函数或验证当前势函数已可优化。欧氏距离不能证明能引导进入避让区。替换为导航势函数时必须同时证明其 Lipschitz 常数和期限裕量，不能沿用 L=4。

上式给出新的数学联系，尚未给出足够小风险的可行控制，也未修复投影弱活动点的梯度问题。下一步须依次验证：已存轨迹的逐例事件上界、真实轨迹的优化方向、阈值是否存在可行策略、独立初态/噪声及两冻结基线种子上的死锁和 timeout 降幅。训练保持 min J_def s.t. E[R]≤epsilon 以及原始—对偶更新；不以固定权重实验替代约束训练验收。
