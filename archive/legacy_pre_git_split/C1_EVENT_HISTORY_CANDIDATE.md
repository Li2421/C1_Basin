# 固定预测时域、历史事件守卫候选

本候选改变预测风险的事件语义实现，不是把归档旧风险换种子重跑。控制器仍为冻结Flow-BC、原G_phi物理残差和双硬安全投影。实际评测仍在原首次事件停止。

## 新机制

旧预测在首次死锁停止，改变参数可能改变截断时刻，因而风险会跨离散分支跳变。现在让预测模型在固定原时域T内继续执行同一个控制器，用历史事件公式决定是否发生了原定义的死锁。预测成功后的行为不计为新的任务失败，预测死锁后的成功也不擦除已经发生的失败。

这与新增恢复控制器不同：没有改变或选择控制动作规则，只有预测继续；实际部署不会执行终止后的动作。没有扩大原T、没有场景路线/势函数、没有外部critic。J_def仍只统计实际首次事件前的执行前缀。

## 与原首次事件的等价性（无碰撞条件下）

令a_t为任务未完成裕量，a_t>0等价于该步尚未成功；p_t、v_t为原进展不足及低速裕量。保留原窗口就绪条件与hold样本数。定义

\[
 h_t=\min_{1\le s\le t}a_s,\quad
 w_t=\min_{s=t-L+1}^{t}\min(a_s,p_s,v_s),\quad
 \rho_D=\max_{\text{完整有效窗口 }t}\min(w_t,h_t).
\]

rho_D>0当且仅当某个完整停滞窗口发生，且此前未成功。若死锁之后才成功，先前的正窗口保留在max中；若先成功，后续所有窗口的h_t<=0，均不能触发正事件。

原末端stalled判据裕量s_T使用同样的最后40个动作速度和原两端点进展差，定义rho_S=min(s_T,h_T)，rho=max(rho_D,rho_S)。若原首次事件为成功，二者非正；若原首次事件为严格死锁，rho_D为正，不论模型后来是否恢复；若此前无成功/死锁，则T时rho_S符号与原timeout末端stalled判据一致。因此rho>0对应原strict或stalled死锁联合事件。精确边界0按原严格比较保留，不冒称严格正事件。

候选风险为

\[
 R=\frac{\operatorname{softplus}(\rho/0.1)}{\log2}.
\]

温度0.1在新轨迹结果前固定，对应原归一化谓词裕量的十分之一尺度，不做结果调参。D时R>1，非D时R<=1；故1_D<=R并有P(D|x)<=E[R|x]。风险并非校准概率，上界下降不自动等于实际死锁下降。

## 梯度性质和边界

对固定长度的连续谓词序列，有限次min/max及softplus为连续函数，改变哪个时刻是首死锁不再触发截断长度切换。仍有min/max拐点及硬投影弱活跃点，不能称为处处可微。整个闭环的连续性还依赖控制器/投影映射及可行性条件；没有据此证明期望与微分全局可交换、C1全局收敛或脱困成功。

历史守卫防止事件改名，但梯度仍可能先降低某个严重度而未消除首次死锁，所以必须执行独立提前预测与匹配扰动对照。首次事件后的模型轨迹只是计算构造，其有效性通过前缀等价及历史事件公式检验，不能把模型后续成功算作实际完成。

## 实现状态

`risk/event_history.py`和`rollout_event_history.py`已实现。4项CPU逻辑测试通过，包含100组随机谓词序列与独立首次事件遍历对照、先死锁后恢复、先成功后停滞、窗口切换连续性例子。Job50的3个新起点CPU前缀/J_def检查已通过：原执行在565/755/523步成功，预测均继续至850步；最大前缀动作差8.94e-8，原安全检查全零。三例恰好均为成功，不能据此声称真实严格死锁和stalled情形都已回放覆盖；这些事件的逻辑性质由独立谓词测试覆盖，真实事件对应还须在后续约50组测试中核查。这不是避锁效能证据，不直接训练。

条件事件边界积分暂不进入机器人实验：事件区间完整性证书尚未解决。其解析代码保留为研究工具，不将稀疏噪声扫描冒充概率上界。
