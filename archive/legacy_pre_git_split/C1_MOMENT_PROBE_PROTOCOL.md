# 均值—方差候选一次性机器人筛查（2026-09-18）

运行前冻结；不依照结果搜索参数。25个closer_interaction独立起点，4个预测噪声/点（100条全时域预测及裕量反传），2个独立执行噪声/点，50组四臂配对案例，共200次真实首次事件执行。零输出初始化的当前G_phi，冻结Flow，双投影，原事件strict/stalled与普通timeout分别记录。不训练。

定义rho为event_history的原事件裕量，仅复用其事件语义，不复用已归档评分。无碰撞模型续演、原检测器阈值和时域下D推出rho>=0；边界等号单独按检测器处理。K=4，m=mean(rho)，v=mean((rho-m)^2)，s0²=.01，r=m/sqrt(v+s0²)，R=1/(1+relu(-r)^2)+softplus(r)。选择s0=.1是事件归一化裕量的固定十分之一，避免默认.001尺度放大低方差批次，不作参数搜索。逐批次Cantelli界保证事件比例<=R，因此正确边际噪声分布下E[R]>=P(D)，单批次不是总体置信界或校准概率。

梯度：dR/du=sum_i (dR/drho_i)(drho_i/du)，其中dr/drho_i=1/(K sqrt(v+s0²))-m(rho_i-m)/(K(v+s0²)^(3/2))。每条裕量沿冻结Flow、当前G_phi、动力学及两个硬投影的现有JAX分支VJP反传。非光滑/弱活跃处该VJP不保证等于所有单侧方向导数；故此为必须由真实配对回放验证的候选方向，不冒称概率梯度。无学习式估计器。

干预仅前100步（5秒），第二投影前动作残差；预测噪声上校准投影后RMS=.0025，分量上限=.025。正负梯度及独立随机方向，同一独立未来噪声四臂配对。校准只匹配幅度，不搜索路径或结局。真实动作幅度偏差<=10%，否则对照未通过。
